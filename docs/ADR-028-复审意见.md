## 1. 复审结论

### 1.1 已闭合项

- **三文档基线已同步**：设计 v1.19、需求 v0.13、P1 计划 v0.8、UI-UX v0.9、AGENTS 均声明 ADR-028 v0.4；ADR §5.1–§5.5 与实际文档版本一致。
- **10 项用户裁定已落文**：
  - 共享 token **暂定接受**（ADR §2.3/§9）；
  - 三官方运行时均支持多供应商（ADR §2.1-5、设计 D10、需求 UI-09、P1 计划 M7-10）；
  - `multi_provider` 静态能力（ADR §2.1-4、设计 D6:437）；
  - 三运行时 `provider_id` 必填、无自动选择（ADR §2.1-4/§3-2、设计 D7:486）；
  - 停用/删除只读（ADR §2.1-4/§3-5、设计 D7:486、UI-UX §2.4/§3.3）；
  - 端点用户输入风险（ADR §2.3/§3-11、设计 D10:591、UI-UX §5.1）；
  - 目录查询 `provider.catalog.get`（ADR §2.1-6、设计 D6:430-434）；
  - 全局设置记忆 `ui.provider_selection`（ADR-018 A-6、设计 D7:488、P1 计划 line 7）；
  - 扫描排除测试代码/合成 key 白名单（ADR §2.4、P1 计划 DoD 7）；
  - 5 个 UI 锚点、UI-UX 计数 15→20（UI-UX §7.3）。
- **配套登记已做**：ADR-018 v0.3（设置键 8→9）、ADR-010 v0.7（`SessionSummary` 三字段）、P1 计划计数 20→21 / M7 9→10 / 直接实施 3→4 / L 12→13。
- **约束未破**：命令面 63、事件、错误码、迁移 `0009` 不变；目录查询为 D6 只读方法，不新增 IPC 命令。

### 1.2 仍未闭合项

1. **P0-1 旧会话“补选”无路径**：ADR/设计/P1 计划均要求旧会话无 `provider_id` 时“补选并持久化后”才可 send/retry/resume，但命令面 63 不变、`SessionSendRequest` 无 `provider_id`、也没有 `session_set_provider` 命令或 UI 重选锚点。该要求当前不可实现/验收。
2. **P1-1 目录查询协议语义不足**：`provider.catalog.get` 是 adapter→core 请求/响应；现有 D6 方法表是 core→adapter，adapter→core 只有通知。设计未定义入站请求分发、ID 命名空间/待决表、超时/取消、未知方法、错误映射；且 `core_not_ready`/`invalid_value` 是 IPC 错误码，不是 JSON-RPC 线协议码。
3. **P1-2 静态能力到 UI 的数据通路缺失**：`multi_provider` 静态表只在核心；`runtimes_list`/UI 仍从 `hello.capabilities` 读取；冷启动/未 ready 时 UI 可能不显示供应商选择，且 `SessionWorkbench` 仍按 `capabilities.includes("multi_provider")` 决定是否透传 `provider_id`。
4. **P1-3 D6 能力判定自相矛盾**：设计 D6:436 仍写“判定时机 = runtime ready 后”，与同段的 `multi_provider` 静态判定冲突。
5. **P1-4 设计 §5 P1 退出标准仍写“M5–M8 全部任务 DoD”**：M7-10 是直接实施项、不构成门禁，与 P1 计划/ADR-014 决策 7 冲突。
6. **P1-5 设计附录 A UI-09 未同步多供应商**：仍只写“消费映射/连通性测试”，缺 ADR-028 v0.4/M7-10/D6/D7/D10，需求→设计→任务→验证链路断裂。
7. **P1-6 `model` 省略行为未定**：三运行时 `provider_id` 必填，但 `model` 仍可选；省略时后端不做“模型属于 provider”校验，Claude/Codex/DSH 会用自身默认模型，可能不被该 provider 支持。
8. **P1-7 UI 只读态禁用中断**：UI-UX §2.4 矩阵把“供应商失效/删除”的中断也置禁用，但 ADR 明确“不中止当前在途 run”；用户应能中断当前 run，只是不能发新消息。
9. **P1-8 内置 OpenAI `/v1` 修正未进设计**：ADR §2.1-3 要求历史 `https://api.openai.com` 补 `/v1`，设计 D10/D7 无对应条款；实现缺设计依据。
