## 2. DoD2 安装产物与干净机冒烟

### 2.1 本机 Windows 产物

- 构建入口：`node scripts/ci/build-desktop-installer.mjs --out dist-out/m8-04`
  （三官方运行时包 + `runtimes.json`/`digests.json`；DSH pin 0.2.1-rc.2；WiX MSI，
  WebView2 `embedBootstrapper`）。
- 结果（2026-10-20）：
  - 前端构建、三官方运行时 bundle、Rust **release 编译成功**（`target/release/aether-tauri.exe`，
    `Finished release profile in 8m 03s`）；
  - Tauri bundler 在 `Info Verifying wix package` 后卡在
    `Downloading https://github.com/wixtoolset/wix3/releases/download/wix3141rtm/wix314-binaries.zip`；
    本机 `%LOCALAPPDATA%\tauri\WixTools314` 不存在，等待 30+ 分钟无进展；
    PowerShell HEAD 可达（HTTP 200，41,297,555 字节），但 `Invoke-WebRequest`/`curl` 下载均
    在数 MiB 后连接重置；随后终止卡住的构建进程（exit 1，未产出 MSI）。
  - **DoD2 本机产物：阻塞（WiX 下载）**；解除方式：预置 `WixTools314` 离线缓存后重跑，
    或由 `release-desktop-installers.yml` 在 CI 产出。
- 干净机冒烟步骤（发布前人工/CI）：见 `docs/打包与发布说明.md` §6.3。

### 2.2 三平台编排

- Windows MSI / macOS DMG：`.github/workflows/release-desktop-installers.yml`（M4-05 既有）；
- Linux 打包仍为 P1 条件项（ADR-014 决策 5；不构成 P1 门禁）；
- 安装器哈希：`dist-out/SHA256SUMS.txt` + `scripts/test/m8-04/generate-sbom.mjs` 归档。
