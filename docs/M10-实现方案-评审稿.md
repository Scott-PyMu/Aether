## 2. M10-03：axum HTTP/WS/CLI

### 2.1 依赖

| crate | 版本 | 用途 |
|---|---|---|
| `axum` | `=0.8.9` | HTTP 路由/JSON/WS/body limit；`default-features=false`，`http1/json/tokio/ws/tracing` |
| `tokio-tungstenite` | `=0.29.0` | CLI 原生 WS |
| `ureq` | `=3.4.2` | CLI RPC（`default-features=false`） |
| `getrandom` | `=0.3.4` | token |
| `futures-util` / `hex` / `serde` | `0.3` / `0.4` / `1` | WS split / hex / 结构 |

- **workspace `rust-version` 1.80 → 1.85**（`ureq 3.4.2` MSRV 1.85）。
- 新增依赖先查 `deny.toml`；`cargo deny`/`pnpm check:licenses` 通过；精确 patch 锁定。

### 2.2 模块与生命周期

```text
crates/aether-daemon/src/api/{mod,auth,discovery,http,ws,limits,errors}.rs
crates/aether-daemon/src/bin/aether.rs
crates/aether-daemon/src/cli/{args,client,output,commands}.rs
```

- `IpcState` Clone；HTTP 用 `spawn_blocking` 调同一 `dispatch`；错误映射与 stdio 共用。
- `--stdio` 默认不启 HTTP；`--stdio --http`/`AETHERD_HTTP=1` 开启；`--http-only` 开启且 listener 失败致命（退出码 25）；`AETHERD_HTTP=0`/`--no-http` 关闭；与 `--http-only` 冲突报参数错误。
- Windows 关闭事件使用 **Tokio `tokio::signal::windows`**（`ctrl_c`/`ctrl_break`/`ctrl_close`/`ctrl_logoff`/`ctrl_shutdown`）；**不引入 unsafe/windows-sys**；`ctrl_close` 触发优雅关闭（≤1s 停止接受/≤3s 在途/WS 1012/删发现文件），console close 约 5s 按 best-effort 记录。
- 仅 HTTP 开启时写 `.aetherd-api.json`（0600/DACL），关闭删除；`--http-only` 仍用同一 `.aetherd.lock`，禁止双 daemon。
- 关闭：停止接受（≤1s）→ 在途（≤3s）→ WS 1012 → 删发现文件；包含在 daemon 8.2s 内。
- `initialize` 后启动 listener；warm 后 `attach_feed`；listener 失败在 `--stdio --http` 下不致命（`health.api.state="error"`）。

### 2.3 API/CLI

- `POST /v1/rpc`（单请求，body/响应 ≤2MiB）、`POST /v1/rpc/cancel`（best-effort）、`GET /v1/meta`、`/v1/health`、`GET /v1/events`（WS）、`POST /v1/admin/rotate-token`。
- `/v1/meta` 只列已实现命令；最终 87。
- WS：首帧 auth、subscribe/last_seq、gap/readback、4096 队列、1013 重连。
- CLI `aether`：session/workflow/subagent/import/export/health/events/api；`events` 用 `tokio-tungstenite` 原生 WS，JSONL 输出；退出码 0–7。
- OpenAPI/JSON Schema：`docs/api/aetherd-v1.openapi.json` + `docs/api/schemas/*.json`；`scripts/ci/api-schema.mjs` 字段级校验 + 命令覆盖 + diff=0。
- token 不入 URL/日志；CORS 默认拒绝；100 req/s、64 连接、body 2MiB；远程绑定需 ADR。

### 2.4 验收（G10）

单测（token/发现/限流/错误映射）、集成（HTTP 63 命令抽样/端口/关闭）、WS（auth/last_seq/gap/1013）、CLI（每命令/退出码）、四通道 0 差异、10 并发不串流、外部消费者脚本。**HTTP 默认关闭**的测试单独覆盖；Windows `ctrl_close` 用手动关闭控制台/`GenerateConsoleCtrlEvent` 覆盖。

## 3. M10-05：UtilityProcess 图像解码/缩略图

### 3.1 解码库

| 组件 | 版本 | 许可证 | 职责 |
|---|---|---|---|
| `@napi-rs/image` | `=1.16.0` | MIT | PNG/JPEG/WebP 解码、EXIF 旋转、缩放、WebP 编码 |
| `omggif` | `=1.0.10` | MIT | GIF 首帧 → RGBA |

- 不用 `sharp`/`@img/*`（避免 LGPL/体积/供应链）。
- `@napi-rs/image` 无 `limitInputPixels`：**构造 Transformer 前**读文件头宽高/像素，拒绝 >25MP/最长边 >8192；GIF 同理。
- 三平台 N-API/asarUnpack spike 先行（Windows MSI、macOS **未签名 DMG**、Linux deb/AppImage）；失败停止，不回退 renderer 解码。

### 3.2 流程

```text
renderer（只展示缩略图）
  └─ <img src="aether-attachment://thumb/<sha256>">
        ↓
Electron main（路径校验/协议/调度，不解码）
  └─ utilityProcess.fork(attachmentWorker.cjs)
        └─ @napi-rs/image / omggif → 512px WebP q80
```

- `attachment_add` 返回 `AttachmentSummary`（**无 storage_path**）：`attachment_id/sha256/mime/size_bytes/width/height/created_at`。
- renderer 用 `sha256` 构造缩略图 URL；main 按 `mime→ext` 找 `<data_dir>/attachments/<sha[0..2]>/<sha>.<ext>`，缓存 `<data_dir>/attachments/thumbs/<sha256>.webp`。
- 协议只允许 `GET /thumb/<64hex>`；CSP `img-src` 增 `aether-attachment:`；不返回原图。
- UtilityProcess：受限进程（**非沙箱**）；无网络/无 shell 仅代码约束；并发 2/队列 16/单图 10s/空闲 60s/崩溃重启 1 次。
- 格式 PNG/JPEG/WebP/GIF；单文件 10MiB/单条 8/单会话 200/1GiB/25MP/8192；EXIF 剥离；GIF 首帧。
- macOS 签名/公证不纳入；未签名 DMG 烟测 UtilityProcess 加载/缩略图。

### 3.3 验收（G11）

四格式/损坏/伪造 MIME/超限/25MP 边界/EXIF/元数据；host 懒启动/并发/超时/崩溃/协议白名单；E2E 粘贴/拖拽/选择/删除/重试/重启缓存；三平台打包；日志/诊断 0 内容泄漏；10 并发内存基准。

## 4. M10-02：子 Agent 结果注入（最终口径）

### 4.1 数据模型（0010+，22 规划位）

```sql
CREATE TABLE subagent_results (
  child_session_id TEXT PRIMARY KEY REFERENCES sessions(id) ON DELETE CASCADE,
  result           TEXT NOT NULL,          -- canonical JSON <=64KiB
  total_bytes      INTEGER NOT NULL,
  truncated        INTEGER NOT NULL DEFAULT 0,
  verdict          TEXT,
  summary          TEXT,                   -- <=512 字节（UTF-8），不是字符
  summary_truncated INTEGER NOT NULL DEFAULT 0,
  findings_count   INTEGER NOT NULL DEFAULT 0,
  created_at       INTEGER NOT NULL
);
-- 不加 (parent_session_id, created_at) 索引：表无 parent_session_id 列；按 child PK 查，
-- 父列表走 sessions(parent_session_id,status) / subagent_injections(parent_session_id,state,created_at)。

CREATE TABLE subagent_injections (
  id                 TEXT PRIMARY KEY,
  parent_session_id  TEXT NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
  batch_id           TEXT NOT NULL,
  child_session_ids  TEXT NOT NULL,
  payload            TEXT NOT NULL,        -- compact envelope <=8KiB
  result_refs        TEXT NOT NULL DEFAULT '[]',
  state              TEXT NOT NULL,        -- pending|injected|folded|rejected|superseded
  mode               TEXT NOT NULL DEFAULT 'message_append', -- message_append|origin_fork|system_replace
  supersedes_id      TEXT,
  requires_approval  INTEGER NOT NULL DEFAULT 0,
  context_version    INTEGER NOT NULL DEFAULT 0,
  created_at         INTEGER NOT NULL,
  injected_at        INTEGER,
  folded_at          INTEGER,
  UNIQUE (parent_session_id, batch_id)
);
CREATE INDEX idx_subagent_injections_ctx
  ON subagent_injections(parent_session_id, state, created_at);
```

- 完整结果 `result_ref = "subagent:<child>"`；`subagent_list` 只读 verdict/summary（512 字节 UTF-8）/summary_truncated/findings_count/injection_state/result_ref/has_more_details。
- `subagent_result_get`：`{parent_session_id, child_session_id, offset?, limit_bytes?}`；UTF-8 字节分页 16KiB/页、最多 4 页；父会话授权。
- `subagent.result.get`：适配器方法（10s），参数同样含 `parent_session_id`；不计 IPC。
- **Q5 Gate（v1.2）**：先 mock/单测（capability/ack/version/mode/fold/restart/失败）；真实三运行时至少 `message_append`；硬门禁 = 隔离/exactly-once/不污染/后台无 intervening turns/权限审计/ack/version/supersedes/fold/restart；缓存 best-effort，非硬门禁；不阻塞 M10-03。
- **父授权**：校验 `child.parent_session_id == parent_session_id`；兄弟/堂兄弟/根直读拒绝且不泄露存在性。
- **父删除**：`session_delete` 有子会话 → `session_has_children`；不级联、不改父指针、不产生 `session.closed`；UI 置灰。

### 4.2 交付/汇总/折叠

- 完整结果 ≤64KiB（表）；compact envelope ≤8KiB/批：`verdict/summary/counts/top_findings≤5/conflicts/children≤16/result_refs`。
- 同 `batch_id` N 条 → 1 条 injection；verdict 优先级 `reject > needs_changes > approve > info`；findings 去重；部分失败保留成功并标 `failed_children`。
- `state=pending` 落库；父会话**安全边界**（空闲/无在途 run/新 run 前）才交付；运行中不插队。
- 组装层：最近 8 条 envelope 原文 + 1 条折叠摘要（≤2KiB），总 ≤16KiB；更早 `folded_at`，payload 保留；父 Agent 仍可拉取。
- **交付模式（v1.2）**：
  - `message_append`（默认）：父 system prompt 不变；compact envelope 作为 tool result/合成 user message，带 `version`/`supersedes`/`result_refs`；旧行 `superseded`；追加成功 ack 后置 `injected`；缓存前缀稳定（best-effort）。
  - `origin_fork`（后台）：delegation boundary 冻结 origin fork；callback = fork + 结果；新 ephemeral provider context；不读 live history；输出追加 live timeline；允许 cache miss。
  - `system_replace`（可选严格）：Claude `--system-prompt-snapshot off` / DSH section；大 system 块可 cache miss；不作为默认。
- `session.send.subagent_context: {version, block, mode?}`；能力 `subagent_context`；ack `applied_context_version` + `applied_context_mode`；core 仅在 version/mode 匹配后置 `injected`；未声明/不支持 mode → `subagent_context_rejected`/hold，不静默降级。
- `subagent.completed`：`batch_id` + `injected` 必填；**不新增 `subagent.injected` 事件**；`subagent_list`/`resolve` 后 refetch。
- `subagent_resolve` 返回 `{decision,injected,injection_id?,context_version,mode,new_child_session_id?}`。

### 4.3 验收（G9）

8 并行 → 1 条 injection ≤8KiB；父上下文 ≤16KiB；完整结果逐页可拉；父运行中不注入；hold/accept/reject/rerun；折叠 8 条；重启不重复；父授权/父删除；隔离/权限原断言；审计 `subagent.result.pulled`（不记内容）。
