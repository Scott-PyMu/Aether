## 4. 契约与边界声明（登记）

- `artifacts` 引用 = **持久化引用，不预授权**：Agent 读取仍经 `fs.read` 权限门、写入仍经 `fs.write` 审批（D9 不变）；「附加文件夹」不调用 `workspace_set`；
- `artifact_add` 校验 = canonicalize + `stat` 可访问性（**不复用 A4 同步盘检测**，2026-09-24 评审裁定）；拒绝码统一 `artifact_path_rejected`（不含同步盘语义，与 `path_rejected` 分工见 ADR-010 B.3）；
- `ref_pick` 为 Rust 侧系统选择器（`DirectoryPicker` 扩展 `pick_file`），不新增 WebView capability；
- P0 边界：不列目录、不展开文件树、不预览/编辑、不读文件字节、无「改动」tab 入口、无拖拽/@ 引用（ADR-010 决策 1「不在 P0」）。
