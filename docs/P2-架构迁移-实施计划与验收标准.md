## 0. 阅读规则

- 任务 ID：`M9-xx`（架构迁移）、`M10-xx`（P2 协作底座功能）；`★` 标记关键路径。
- DoD 全部可执行验证：单测 / 集成 / E2E / 故障注入 / 脚本 / 检查；禁止「完成开发」「已实现」类表述。
- 每个任务必须有证据文档；每条 DoD 必须给出可复跑命令或脚本。
- **Tauri 仅开发期对照**：M9 前段可用于对照，M9-08 后 HEAD 不再构建 Tauri；不生成/不保留回退包；`AETHER_SHELL=tauri|electron` 仅开发/测试使用。
- **不修改已发布迁移文件**（AGENTS §8）；M9 不新增迁移。
- **不放宽测试断言**：Tauri 边界测试要等价迁移到 daemon/Electron，不得删除后声称通过。
- 量级用于并行分组，不作为日历承诺；关键路径按依赖图重算。
- 资源假设：2–3 名开发者 + 1 名兼职评审；若实际人数不同，M9 的并行组（M9-05/06、M9-09/10）需重新收敛。

## 1. 总览

### 1.1 目标与非目标

**目标**

1. 把 `aether-tauri` 中的业务层抽成 **`aether-app`**（transport-agnostic），新增 **`aether-rpc`** 与 **`aetherd`**，保持 63 命令/32 错误码/事件/数据契约不变。
2. 用 **Electron** 替换 Tauri 壳：main/preload/renderer、`WebContentsView`（UI-06 基础）、`UtilityProcess`（Node/MCP 承载）、单实例/生命周期/退出/崩溃恢复。
3. 保持旧数据可直接打开；备份/恢复/加密/Keychain/审计/设置/预设/工作区全部回归。
4. 建立可复跑的 M9 门禁与证据；G8 后 Tauri 退役，Electron 成为默认壳。
5. 为 M10/P2（编排引擎、子 Agent、HTTP/WS/CLI、导入导出、多模态、i18n、调度器）提供 headless daemon 地基。

**非目标（M9 不做）**

- 不重写核心业务（Rust 核心 crate 保持不动；仅移动应用层）。
- 不新增命令、不新增事件类型、不新增迁移、不改 DB schema。
- 不做 UI-06 的完整交互（标签/分屏/下载/权限 UX 属 **P4**；M9 只做 `WebContentsView` PoC + 安全基线）。
- 不做自动更新器（P3 另立 ADR）。
- 不做 HTTP/WS/CLI 对外 API（M10-03）。
- 不做第三方适配器/沙箱（P3）。
- 不做移动端。

  4. **往返一致**：导出 → 导入 → 再导出，行数/哈希/关键字段一致（排除时间戳等易变字段）；messages/events 对齐；审计/权限/引用不丢失。
  5. **大库**：≥1GB 归档抽样；导入中断（kill）可恢复/可清理；空间检查；进度与取消。
  6. **安全**：密钥/`api_key`/token 0 命中；路径逃逸/压缩炸弹/超大行拒绝；导入不触发工具执行/网络请求。
  7. **UI/审计**：导入/导出入口、结果/警告、失败恢复；审计 `import.*`/`export.*`（按 ADR 登记）；E2E。
  8. **回归**：备份/恢复、保留/归档、会话检索不受影响。
- 证据：`docs/M10-04-证据.md`（往返、故障注入、大库、脱敏、E2E）。

## 6. 风险与失败处理

| 触发 | 动作 |
|---|---|
| G1/G2 命令不等价 | 停止迁移；修 `aether-app::dispatch`/路由；不得删除命令或放宽断言 |
| 大响应超 2MiB/预算 | 分页/`max_bytes`；只失败本请求，不重启 daemon；G2/G3 复跑 |
| DB 可打开但 `quick_check` 失败 | **只读安全模式**（`persist_degraded`/S-08/导出/备份）；不退出、不丢库；仅 DB 无法打开才 S-12/22 |
| 退出预算超时 | 按 §3.6 预算/强杀点修；保证 drain 先于 checkpoint；T11 复跑 |
| daemon 锁失效 | 停止发布；修 OS 锁；禁止 `busy_timeout` 降级 |
| S-01/S-12/S-13 未登记 | 不进入 G4/G5；先补 UI-UX v0.17 锚点/文案 |
| G3 事件乱序/丢失 | 停止发布；修 transport writer/批处理；10×50 复跑 |
| G4 安全基线失败 | **停止发布；修 flags/CSP/preload/隔离；重跑 G4**（无回退包） |
| G5 数据丢失/Keychain 不可恢复 | **停止发布；修 preflight/恢复**；禁止发布 |
| G6 安装/签名/公证失败 | **停止发布；修安装/签名**；重跑 G6（无旧 MSI 升级链） |
| G7 P0/P1 回归失败 | **停止发布；修回归**；不得带病切换 |
| M10-00 ADR 未通过 | 对应 M10 任务标注「未解锁」，不得写代码；先补 ADR/登记 |
| G9 编排/子 Agent 失败 | 冻结 M10-01/02/07；修隔离/调度；不得以「演示通过」替代 10 并发/权限断言 |
| G10 多客户端失败 | HTTP/WS/CLI 不发布；stdio 仍为唯一正式通道；修鉴权/一致性 |
| G11 导入/多模态失败 | 不发布导入/多模态；修原子性/脱敏/附件清理 |
| G12 i18n/主题失败 | 不阻塞后端；修 key/布局；不得隐藏缺失文案 |

| 子 Agent 上下文污染 | 显式上下文/引用；结果结构化；父可拒绝；隔离测试 |

**失败处理步骤（无回退包）**：

1. 任一 Gate 失败 → **停止发布**，不部署「部分 Electron」；
2. 保留故障现场/日志/基线差异，定位并修复；
3. 可回退到**上一 Electron 候选构建**（若已归档）；**不回装 Tauri**；
4. 记录失败原因/版本/数据状态；修复后重跑对应 Gate。

**M10 回退**：

1. 关闭对应功能入口/默认开关，不发布该 M10 能力；
2. 若 `0010+` 迁移已应用且失败：按迁移回滚/备份恢复；不得手工改库；
3. 保留 M9 基线（Electron + aetherd + 63 命令）可运行；
4. 修复后重新走对应 Gate，不以「部分完成」宣称 P2。

## 7. 变更控制

- M9 只执行 **ADR-029 v0.4** 已定义的决策；M10 功能必须先经 M10-00 ADR 批次登记，新增命令/事件/设置键/迁移/协议 breaking change 未登记不得实现。
- ADR-029 v0.4 的裁定项（R-P0-1/R-P0-2、R-P1-1～R-P1-5、§9.4、§11 R1–R9）必须落到任务 DoD/证据；未落项在 M9-01 证据中标注「未关闭/风险接受人」。
- 不修改 `migrations/0001–0009`；M10 新列/索引/约束一律 `0010+`，并与附录 C、`verify:m1-03` 同批；不修改 `packages/protocol` 生成物（由生成器产出）。
- 不以「迁移需要」为由放宽 P0/P1 DoD；Tauri 边界测试等价迁移，不删除断言。
- 不以「P2 功能需要」为由绕过 D9 权限网关/事件登记/命令面计数；UI-UX 文案/锚点变更走 UI-UX 版本。
- 每个任务证据必须引用对应 ADR 条目；Gate 报告必须列出「未关闭项/风险接受人」。

## 8. 开放问题

1. **Linux（已裁定）**：M9 G6 只做构建 + CI 冒烟（deb/AppImage），不纳入签名发布门禁；发布签名/分发在 **P2 之后的阶段（另立计划）**。Win/mac 为 M9 发布门禁。
2. **代码签名/公证凭据**：阻塞 G6；无证书不得宣称 G6 通过（beta 说明不替代签名）。
3. 自动更新（P3）方案；M9 不做。
4. MCP owner：Rust `rmcp` vs Node `UtilityProcess`（P3；M10 不做 MCP）。
5. UI-06 交互细节（标签/分屏/下载/权限提示/会话隔离）——P4 规格；M9 只做 PoC。
6. **macOS Keychain**：M9-09 真机验证；阻塞 G5；失败走 S-13 重授权/口令，不删除旧条目。
7. **无 Tauri 回退包**（用户裁定）：失败=停止发布/修复/重跑；可保留上一 Electron 候选构建；正式发布前重评数据兼容/回退策略（ADR-029 §15-12）。
8. **Electron 版本**：M9-01 锁定当前稳定线精确 patch；安全更新 ≤30 天；major 升级需冒烟。
9. M10-00 冻结项：工作流 DSL/节点类型、子 Agent 默认深度/fan-out/权限继承、HTTP/WS 端口与发现、导入 ID 重映射策略、多模态格式/限额、i18n 语言/主题 token、调度器是否抢占、事件分库判定阈值。
10. **阈值（硬）**：`安装包 ≤1.5× M9-01 HEAD 基线且 ≤450MB`、`idle RSS ≤500MB`、`10 会话 ≤1.2GB`；G6/G7 超限即不通过，不设自由裁量豁免。
