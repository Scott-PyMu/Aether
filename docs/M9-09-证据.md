## 6. daemon 单实例锁与锁生命周期

- 锁文件：`<data_dir>/.aetherd.lock`，`fs4`（Windows `LockFileEx` / Unix `flock`）独占句柄；
- 顺序：`StartupGate` 解析数据目录 → `DataDirLock::acquire` → A4 → `aether_store::preflight`（DB 打开 + checksum；**不迁移**）；

- kill -9/Electron 崩溃：OS 释放句柄；无「存在性锁」陈旧问题；`.aetherd.lock` 不参与数据复制；

## 8. Keychain preflight（S-13）

- `crates/aether-app/src/keychain_preflight.rs`：只读 `SecretStore::get` 探测 `keychain://aether/provider/<id>`；`readable/missing/unavailable`；`unavailable>0 → mode=reauth`；**不调用 delete**；
- `boot.rs` 执行 `run_boot`：密钥存储未挂载且存在 provider 时报告 `mode=reauth`（全新安装无 provider 不误报）；`serve.rs` 在预热完成时推送 `daemon.status.reason=keychain_reauth_required`；
- main 收到后显示 S-13（mode=reauth；页面同时提供口令降级输入）；**不调用 `startup_get`**（M9 保留命令不暴露，M9-07 静态门禁保持通过）；
- S-13 动作：重试授权（重启 daemon 重新 preflight）/ 口令降级（重启 daemon 并注入一次性 `AETHER_SECRETS_PASSPHRASE`，不落盘/不日志/诊断包剔除）/ 跳过（降级）；旧条目不删除。
