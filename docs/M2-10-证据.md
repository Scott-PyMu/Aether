## 4. 边界与偏离记录

1. **`permission.request` 通知形状（增量定义）**：D6 仅固定方法名，M2-10 冻结参数为
   `{request_id, session_id?, run_id?, resource, action, target?, content_bytes?}`
   （未知成员忽略，只增不改语义）。`session_id`/`run_id` 为关联/诊断所需；
   `runtime_id` **不采信通知字段**，由连接 `hello` 上下文注入。
2. **`permission.resolve` 请求形状**：`{request_id, decision, scope, reason}`——
   `reason` 为 D9「拒绝回传 reason」要求的增量成员（Mock/适配器忽略未知成员）。
3. **会话映射（测试口径）**：集成测试以适配器会话 id 作为核心 `sessions.id` 构造会话行
   （1:1）。生产侧「核心会话 ↔ `sessions.config.native_id`」映射由 M3-02 生命周期接线
   承接（M2-02 已冻结 `native_id` 为恢复键）。
4. **`aether-security` 为 `aether-tauri` dev-dependency**：仅测试目标使用（组装真实
   `PolicyEngine`/`PermissionService`）；工作区内部 crate、已在依赖图内，无新增外部依赖
   （`cargo deny` 通过）。
5. **回环任务台账**：`PermissionLoop` 记录在途任务并提供 `shutdown()`（中止在途决议），
   供核心关闭/重启序列复用（M2-06/M2-08 语义）；探针计数不进入 `health`/日志字段
   （ADR-007 口径：attempt 日志与 health 字段分离，探针为测试/证据专用）。
