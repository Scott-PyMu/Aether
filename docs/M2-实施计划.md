## 2. 批次 1：主链起点 + 权限网关

### 2.1 M2-01 ★ 生命周期管理与 run 串行

- 交付：会话状态机、run 串行（等待队列 1 + `session_busy`）、幂等（持久化去重）、ack 快路径、断流超时。
- DoD 要点：
  1. 状态机全转移单测，非法转移拒绝；
  2. 并行发送 3 条 → 1 执行 / 1 排队 / 第 3 条 `session_busy`（集成）；
  3. 同一 `client_msg_id` 重发不重复；**重启核心后重放同值仍不重复**（ADR-005 持久化去重）；
  4. ack 在消息与 run 行提交后立即返回（不等模型，时序断言）；
  5. 120s 无事件 → run failed 且可重试（时钟注入）；
  6. `runtime_retry` / `runtime_enable` 接入 `IpcBackend`：复用 M1-08 DTO 校验与 capabilities allowlist；M1-10 服务层只做薄适配（契约冻结于 `docs/M1-10-证据.md` §6）。
- 验证入口（建议）：`scripts/test/m2-01/verify-m2-01.mjs` + `pnpm verify:m2-01`；IPC 接线用例补入 M1-08 校验矩阵回归。
- 证据：`docs/M2-01-证据.md`（含重启重放与 ack 时序原始输出）。

### 2.2 M2-03 ★ 权限网关与审批

- 交付：策略矩阵、审批流（pending 持久化 / 300s 超时 deny）、路径校验（Windows 特殊路径）、审计最小写入。
- DoD 要点：
  1. 策略矩阵：fs.read 工作区 allow / 外 deny；fs.write 工作区 ask / 外 deny；exec deny；记忆文件白名单 allow（1MB 上限）；
  2. 路径逃逸样本集 100% deny + 审计：`..`、软链接、Junction、UNC（`\\?\`、`\\server\share`）、8.3 短名、ADS、尾随点/空格、保留设备名（T7）；
  3. 审批流：核心重启后 pending 恢复；300s 超时 deny + 审计（时钟注入）；
  4. T6：100 次并发 ask 无丢失/重复/死锁；
  5. 适配器进程内行为不经此门的边界声明与设计 §2.1 一致（文档检查 + 审计字段）。
- 验证入口（建议）：T7 样本集脚本 + `pnpm verify:m2-03`；审计断言与 M1-07 脱敏口径对齐。

**批 1 出口**：M2-01/M2-03 DoD 证据归档；`pnpm ci:local`（23 项基线 + 新增 verify 步骤）全绿；`cargo clippy --workspace -- -D warnings` 0 告警。

## 3. 批次 2：运行闭环主体铺开

### 3.1 M2-02 首个真实适配器（Claude Code）

- 交付：createSession / sendMessage（流式）/ tools.list / permission / dispose 封装（`runtime_id = claude-code`）。
- DoD 要点：
  1. 一致性测试全用例（含异常路径）；
  2. `tools.list` 与 5 类工具调用事件（正常 / 失败 / 超时中断 / ask 允许 / ask 拒绝，清单见 M1-09 DoD6）对齐附录 B；Runtime 不支持子集在接入笔记记录差异；
  3. T5a 崩溃注入：外部强杀 → **30s 内 Ready**，在途 run 标 failed，按 **Mode R**（`sessions.config.native_id`）恢复续聊；
  4. 连续 50 次真实会话完成率 ≥95%，每个 run 均有终态。
- 注意：真实 Runtime 的可用性受网络/中转稳定性影响（Codex spike 曾现 503），失败 run 必须仍满足终态与重放断言。

### 3.2 M2-04 ★ 背压分级与 journal 补读

- DoD 要点：L2 队列 >4096 拒新 run（`storage_backpressure`，已有 run 不受影响）；L3 控制投递 >32MB 或 >会话数×5000 熔断重启 + journal 补读零丢失；订阅者减速下心跳/中断 ≤2s；`Lagged(k)` 最终一致；存储侧背压例外（暂停 ≤2s → 超阈值隔离 `degraded`；队列 ≤1024 持续 30s 自动解除；与 `persist_degraded` 修复路径严格区分）。

### 3.3 M2-05 取消树与看门狗

- DoD 要点：20 会话并发 dispose 全部 10s 内退出；interrupt 后回 idle 可续聊；不响应任务 10s 记录 dump + 强制清理，dump 进诊断包。

### 3.4 M2-06 关闭序列与 checkpoint 纪律

- DoD 要点：drain → 关读连接 → `wal_checkpoint(TRUNCATE)` → 关写连接，五步顺序断言；退出后 `-wal` 为 0 字节、无残留句柄；读锁下 checkpoint 失败 → 退避重试 + 诊断。

### 3.5 M2-07 panic 隔离与健康巡检

- DoD 要点：panic 注入仅该会话 failed；核心 crate `unwrap/expect` 静态 0 告警；RSS 阈值参数化 → 告警 + delta 限流；UI 15s 无响应 → 「核心未响应」+ 重启入口；UI 每 5s 轮询 `health`，E2E 覆盖 `normal` / `persist_degraded` 两态（命令接线已在 M1-05，不在本任务）；**P0 运行期日志汇聚端**（文件/环形缓冲）接线，与 M3-05 诊断包对齐。

### 3.6 M2-09 大行与 OOM 防护

- DoD 要点：>2MiB 任意行不缓冲、断连、记错；1–2MiB 非引用行正常解析（内存曲线受控）；`artifact_ref` 引用流正常、附件不落库仅存 artifacts 路径；1.5GB 压力注入 → 告警 + 限流且不崩溃（联动 M2-07）。

**批 2 出口**：六项 DoD 证据归档；`pnpm ci:local` 全绿；`adapters-platform-tests` 三平台矩阵覆盖 M2-02/M2-09 新增测试；覆盖率不下降。

## 4. 批次 3：孤儿清理与退出可靠性（M2-08）

- DoD 要点：
  1. 强杀核心后重启：PID 复用夹具 0 误杀；token 命中进程被清理；Windows 断言 Job Object 终止路径（`TerminateJobObject` 优先、`taskkill /T /F` 兜底）；
  2. T11：适配器无响应下退出 ≤10s，进程快照无残留；
  3. T5b：Mock 不响应模式 → 10s 心跳连续 3 次失败（≤45s）触发重启，**120s 内 Ready**（不使用 `SIGSTOP`）。
- 复用 M1-10 夹具与跨平台故障注入 helper（ADR-003/ADR-004）；验证入口 `pnpm verify:m2-08` + 快照脚本。

**批 3 出口**：T11/T5b 原始输出归档；`pnpm ci:local` 全绿。
