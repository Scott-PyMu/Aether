### 4.2 安全模式 `backup_restore` 维护例外（R10-A）

新增回归：`crates/aether-daemon/tests/m9_13_safe_mode_restore.rs`。

```text
$ cargo test -p aether-daemon --test m9_13_safe_mode_restore -j 1 -- --test-threads=1
running 1 test
test safe_mode_allows_backup_restore_and_applies_it_on_next_start ... ok
test result: ok. 1 passed; 0 failed
```

覆盖：损坏末页 → `quick_check` 失败 → `persist_degraded` 只读安全模式（不退出）→ `backup_restore` 登记 `requested` 现场日志 → 重启后启动序列恢复 → `storage_state=normal`、旧会话/消息保留、`quick_check=ok`、`backup.restore` 审计。

**本任务修复的缺陷**：`RuntimeControlBackend` 未透传 `backup_list`/`backup_restore`，安全模式下备份装饰器位于其内层，导致维护例外被默认 `not_implemented` 吞掉。修复为显式委派；正常路径行为不变（正常路径备份装饰器在外层）。
