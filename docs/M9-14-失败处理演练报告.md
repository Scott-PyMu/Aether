## 1. 演练口径

本演练不修改真实 Gate 证据/阈值/断言，只对**发布决策模型**注入故障：

1. 基线：G4/G5/G6/G7 全绿 → 允许发布；
2. 对每个 Gate 注入失败 → 决策必须为 `stop_release`，失败 Gate 进入 `rerun_gates`；
3. 修复（恢复该 Gate 证据）→ 重跑 Gate → 决策恢复 `release`；
4. 多 Gate 同时失败 → 全部列入重跑清单，仍停止发布；
5. 回退选择：仅允许 `previous_electron_candidate`；`tauri` 回退请求返回
   `tauri_fallback_forbidden`，仓库不存在 Tauri 候选包；
6. 演练证据写入 `scripts/test/.tmp/m9-14/failure-drill.json`，由 `pnpm verify:m9-14` 校验。

## 2. Gate 与故障注入

| Gate | 通过条件（发布前） | 注入故障 | 期望 |
|---|---|---|---|
| **G4 Electron 壳** | `verify:m9-07` / `verify:m9-08` / `verify:security` 全绿 | preload/CSP/导航/隔离安全基线失败 | 停止发布；修复后重跑 G4 |
| **G5 数据/安全** | `verify:m9-09` / `verify:security` / `m9-13:data` 全绿 | 数据丢失或 Keychain 不可恢复 | 停止发布；修复后重跑 G5 |
| **G6 打包** | `package:desktop` / `smoke:installer` / `verify:m9-11` 全绿 | 安装/签名/公证失败 | 停止发布；修复后重跑 G6 |
| **G7 全量回归** | `verify:m9-13` 全绿 | P0/P1 回归或硬阈值失败 | 停止发布；修复后重跑 G7 |

## 4. 结论

- 任一 G4–G7 失败：发布流程停止，失败 Gate 进入重跑清单；修复后重跑通过才放行。
- 允许保留上一 Electron 候选构建；仓库/发布流程不提供 Tauri 回退包，回退请求被拒绝。
- 本演练是发布决策模型的可执行证据；真实 Gate 失败仍按各 Gate 的 verifier 输出处理。
- 当前真实发布阻塞为 macOS 签名/公证密钥缺失（G6），不是本演练的模拟项；见
  `docs/M9-Gate-G8-报告.md` §4。
