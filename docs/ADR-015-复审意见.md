## 3. 新发现问题（P2）与微项

| 编号 | 级别 | 类型 | 问题 | 依据 | 建议 |
|---|---|---|---|---|---|
| N1 | P2 | 设计（合入文本形态） | **B-3 呈现形态与「规划位=注释、终态=CREATE TABLE 更新」口径不一致**：标题「附录 C 迁移（规划位增行）」下的裸 `ALTER TABLE` 若按字面插入附录 C 正式 SQL 块，`applyDdl` 会将其解析生效（脚本容忍 ALTER），M5-01（迁移未落）时「迁移集 ↔ 附录 C」静态比对将误红，与 §3.1/A-5 声明的「M5-01 不预合入终态」自相矛盾；若仅作注释，又未说明终态在 `CREATE TABLE runtimes` 增列与迁移文件归属 | ADR B-3 `:275-279`；§3.1 `:98`；A-5 `:257-258`；`verify-m1-03.mjs:48-53/185-194` | B-3 拆两段：① 规划位**注释行**（对齐附录 C `:1046-1053` 既有约定，含「终态由 M7-01 DoD7 合入」）；② 终态列更新（`CREATE TABLE runtimes` 增 `enabled`）+ 迁移文件（编号按合入顺序）归属 DoD7 |
