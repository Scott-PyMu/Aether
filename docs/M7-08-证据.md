### DoD2 语义：记忆注入切换 + 权限基准按会话创建固定（R5 + R15）

- 基准 = 会话创建时 `sessions.workspace_id` 对应工作区根（`workspace_id IS NULL` → 数据目录）；**`workspace_set` 换根仅对新会话生效**；**`session_workspace_assign` 不重算**；`workspace_id IS NULL` 会话按数据目录基准。
- 实现：`PermissionService` 拆为「数据目录基准引擎（不可变） + 缺省引擎（当前绑定，只影响新会话/未登记会话） + 按会话基准引擎缓存」；创建时由 `session_create` 登记进程内基准并把快照写入 `sessions.config.aether.workspace_baseline_root`（`null` = 数据目录；键缺失 = 未登记 → 沿用 P0 缺省基准，升级前/非命令路径会话兼容）。
- 改派：在途（`creating`/`running`/`waiting_permission` 或 `queued`/`running` run）→ `session_busy`（`invalid_value` + 稳定业务码前缀，ADR-018 附录 A-7）；空闲 → 原子写 `workspace_id` + 基准快照 `config` + 按目标工作区重合成 `system_prompt` 记忆块（既有预设块原样保留——M7-09 合成口径不覆盖）；审计 `session.workspace_assigned`（detail 显式 `baseline_recomputed=false`）。
- 验证（集成，6 用例含核心断言）：`cargo test -p aether-tauri --test m7_08_workspaces` → **6 passed**：

## 4. 实现级记录（不引入设计未定义决策）

1. **权限基准快照落点（实现级，新增）**：`sessions.config.aether.workspace_baseline_root`（JSON；`null` = 数据目录，字符串 = 创建时工作区根，键缺失 = 未登记 → P0 缺省基准兼容）。理由：R15 要求基准「按会话创建固定」且跨重启不变，而 `sessions.workspace_id` 会被 `session_workspace_assign` 改写；ADR-026 附录 A-1 未为 M7-08 预分配迁移位，故按 M5-01 DoD5① 纪律**不新增/不预合入计划外 DDL**，以既有 JSON 扩展列承载核心自有键（`aether` 段与适配器私有键空间隔离；`native_id` 合并语义不变）。键名/语义登记于本证据与代码常量（`SESSION_CONFIG_BASELINE_SECTION` / `SESSION_CONFIG_BASELINE_KEY`）。
2. **基准解析与失败安全**：会话基准引擎按根缓存；根不可用（canonicalize 失败）→ **fail-closed deny**（不回退到换根后的缺省基准，防止静默放大权限）。未登记基准的会话沿用缺省引擎（P0 兼容，覆盖升级前会话与既有测试夹具）。
3. **改派在途口径**：`creating` / `running` / `waiting_permission` 或存在 `queued`/`running` run → `session_busy`；`paused` 无在途 run（受控中断已收口）不阻断——与 ADR-026 文本一致。
4. **记忆注入切换形态**：仅替换 `system_prompt` 中的「工作区约定」记忆块（`MEMORY_INJECTION_HEADER` 定位，`rfind` 恒取末尾块），既有预设块原样保留（禁止静默覆盖，ADR-026 §2.2-3）；在途适配器会话的既有上下文不追溯（D9 信任级已知边界；新 run/新适配器会话按新提示词）。
5. **删除只删行**：`workspaces` 行删除；磁盘目录/文件不触碰（断言）；不级联会话、不自动改派（ADR-026 §2.1-1）。
6. **`workspaces_list` 计数口径**：`active` = 在途口径（会话状态 `creating/running/paused/waiting_permission` 或存在 `queued/running` run；与 `active_work_counts` 同源），`total` 含终态；未分配会话归入合成组「默认（数据目录）」，**不建 `workspaces` 行**。
7. **命令面计数**：M7-08 +5（`workspaces_list`/`workspace_create`/`workspace_update`/`workspace_delete`/`session_workspace_assign`），错误码 +2；`verify-m4-04` 期望清单同步（当前树另含并行 M7-09 的 +4 命令/+2 错误码；M7-07 后续 +3/+1，合计 63/32）。
8. **`session_not_found` 口径**：改派未知会话沿用 `invalid_value` + `session_not_found` 稳定前缀（ADR-018 附录 A-7：不入 `IpcErrorCode` 计数；`session_not_found` 登记行的实现归 M7-07）。
9. **未改动**：D9 矩阵（改派不改变权限模型）、`workspace_set` 命令语义（缺省绑定）、D14 记忆文件优先级/32KB 上限、迁移 0001–0003（M7-08 无迁移）、`workspaces.memory_files` 列。
