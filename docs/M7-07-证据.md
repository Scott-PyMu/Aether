## 2. DoD 逐条自检

### DoD1 迁移 0008 与校验脚本

- 两张 external-content FTS5 表（`sessions_fts(title)` / `messages_fts(content)`；`content_rowid='rowid'`），迁移内 `rebuild` 回填既有库；六触发器（INSERT/DELETE/UPDATE OF title|content）保持增量同步。
- 不新增显式索引（FTS5 内部影子表不计入 `EXPECTED_EXPLICIT_INDEXES=9`）；`schema_dump`/`m1_03_schema` 过滤 `*_fts_*` 影子表；`verify-m1-03` 静态解析器支持 `CREATE VIRTUAL TABLE`/`CREATE TRIGGER`（触发器体内分号按 `END` 收口）。
- 结果：`node scripts/test/m1-03/verify-m1-03.mjs` **11/11 PASS**；实时 schema **24 表 / 191 列 / 14 外键 / 5 UNIQUE / 9 显式索引**。

### DoD2 搜索语义与性能

- `session_search { query, limit?, offset? }`：query 非空/≤256（超限 `too_large`；空/纯空白 `invalid_value`）；limit ≤100 缺省 20；offset ≥0；用户输入按 FTS5 **短语**转义（`"` 双写），不直接拼接语法。
- 标题与正文双命中，`bm25(sessions_fts) * 5.0` 标题加权；同一会话取最优命中；响应含 `snippet` + `source`（`title|message`）。
- 性能基准（`#[ignore]`，`verify:m7-07` 显式执行）：1e5 会话 / 1e6 消息，20 次查询样本 `[28…51]ms`，**P95 = 49–50ms ≤ 300ms**（两次执行）。
- 结果：`cargo test -p aether-store --test m7_07_session_search` **3 passed**；`--ignored` **1 passed**。

### DoD3 改名

- `session_rename { session_id, title }`：ULID、非空/非纯空白、≤256、控制字符拒绝；`RenameSession` 经单写队列；FTS 触发器同步；审计 `session.renamed`；先日志后广播 `session.updated`。
- payload：`changed_fields=["title"]` + `title`（既有字段 `changed_fields` 即 ADR-025 文本的 `changed`；不新增事件类型，符合附录 B「允许新增可选字段」）。
- 结果：`cargo test -p aether-tauri --test m7_07_session_manage` 内 `search_rename_and_session_updated_event` PASS（事件 + 审计断言）。

### DoD4 硬删除

- `session_delete { session_id }`：事务内复核会话存在；`queued`/`running` run、`waiting_permission`/pending 票据 → `session_busy`（不删除）；成功时删除 `sessions` 行，FK 级联 `messages`/`runs`/`artifacts`/`permissions`；**`events` 不级联**（R7）；审计 `session.deleted`（级联行数摘要 + `events_retained` + `events_cascaded=false`）；广播 `session.closed(reason="deleted")`。
- 删除后 `messages_page` → `session_not_found`（即使 events 行仍在，也不得作为有效补读页）。
- 结果：store `delete_session_refuses_busy_and_cascades_without_events` PASS（busy 两路径、四表级联、events 保留、查无）；tauri `delete_session_cascades_and_keeps_events` / `delete_rejects_busy_and_reports_not_found` PASS。

### DoD5 UI

- 搜索框 `session-search`（250ms 防抖；Ctrl+K/Cmd+K 聚焦；清除）；结果 `session-search-result`（`data-session-id`/`data-source`；snippet 纯文本渲染）。
- 改名入口 `session-rename` → `session-rename-input`/`session-rename-save`/`session-rename-cancel`；删除入口 `session-delete` → `session-delete-confirm-box`（「删除后不可恢复」）→ `session-delete-confirm`/`session-delete-cancel`；错误 `session-manage-error`（`data-code`）。
- 结果：`vitest run src/m7_07_session_management.test.tsx` **5 passed**；桌面全量 **45 文件 / 255 用例**；typecheck exit 0。

### DoD6 并发一致性

- 改名/删除与在途 run、`waiting_permission` 的交互：删除前置在存储事务内复核（单写者串行化），busy 拒绝；改名不改变 run/等待态（仅标题）。
- 删除后 `permissions_pending` 不残留（FK 级联）；store 测试断言 permissions 计数归零。
- 结果：见 DoD4 用例；M3-12 分组/等待态回归 `cargo test -p aether-tauri --test m3_12_waiting_state` **1 passed**。

### DoD7 回归

- `session_list` 过滤/结构不变（未改 `SessionQuery`）；M3-12 分组前端全量通过。
- 命令面/错误码：`verify-m4-04` 清单同步 63 命令 / 32 错误码；`session_not_found` 由 `IpcErrorCode` 真实承载（`map_lifecycle_error` 统一映射；原 `invalid_value + message` 断言按设计变更更新，见 §4-3）。

## 4. 实现级记录（不引入设计未定义决策）

1. **`session.updated` 字段名**：ADR-025 文本写作 `changed`，代码既有契约为 `changed_fields`（`m1_02_contract`/`normalizer` 已锁定）。本任务沿用 `changed_fields` 并新增可选 `title`，不新增事件类型、不改既有字段语义；在证据登记该命名映射。
2. **删除后 events 保留**：`events` 无 FK（0001），删除只级联四表；`session.deleted` 审计 detail 记录 `events_retained`，明确 `events_cascaded=false`（R7）。
3. **`session_not_found` 真实错误码**：ADR-025 附录 A-2 登记；`map_lifecycle_error` 统一映射 `LifecycleError::SessionNotFound`。影响既有 `session_pause`/`session_resume` 的“查无”分支（原 `invalid_value` + message）；按 ADR-006 附录 B 登记更新断言，非放宽。
4. **FTS 影子表**：external-content FTS5 产生 `*_fts_{data,idx,docsize,config}`；schema 比对与 `schema_dump` 过滤影子表，附录 C 只登记虚拟表本身。
5. **搜索只读**：`search_sessions` 走读连接池（4 连接，WAL 并发），不进入写队列；FTS 触发器只随主表写事务同步，不改变事件管线。
6. **删除事务内复核**：`DeleteSession` 在同一事务内检查 run/pending 票据并执行删除；控制层 state 的 active/waiting 预检仅用于快速拒绝，最终以事务结果为准。
7. **UI 搜索输入**：query 原样传后端，短语转义在后端完成；snippet 以纯文本渲染（不注入 HTML）。
