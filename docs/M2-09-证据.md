## 4. 边界与偏离记录

1. **`artifact_ref` 的线协议层与消费侧分层（D6 口径落地）**：连接层只做**形状**校验（失败按「无效帧」计数，D6 失败场景表与坏 JSON 同口径、不断连）；**路径安全**校验（canonicalize + 前缀比较 + 尺寸核对）在 `ArtifactValidator` 消费侧完成（连接无 artifacts 根目录知识）。逃逸引用帧因此不断连——与「适配器进程内行为不受权限门约束」的信任级边界一致（D9），校验是防御纵深而非强制隔离。
2. **「不落库」的断言口径**：aether-adapters 链路无存储依赖（静态断言），连接层是核心唯一数据摄入点，标记字节在所有已解析帧 0 命中 ⇒ 附件数据体没有任何路径进入 `events` 表；附录 B 无附件事件类型（新增类型回归断言覆盖）。「引用帧是否持久化」留待消费侧接入（M2-10/M3）时按 D12 口径决定——MVP 不产生、不持久化附件事件。
3. **监督器生产接线范围**：`RuntimeSpec::with_artifacts_dir` 为机制交付（含单元/集成证明）；aether-tauri 的真实 spec 注册表（`boot_supervisor` 的 specs 来源）尚未落地（M2-10/M3 承接），故无生产侧注入点可接线——与 M2-02 交付口径一致（监督器当前以空注册表启动）。
4. **内存曲线断言上界（常量级调参）**：`MEMORY_GROWTH_BOUND_MIB = 64`（记录于测试注释）；实测 >2MiB 场景增长 2MiB（≈理论缓冲上界）、1–2MiB 场景增长 4MiB，上界为断言容差（对齐 Windows 匿名管道/分配器行为），远低于「按注入量线性累积」的失败模式。
5. **DoD3 回落断言**：释放 1.5GiB 后 Windows `VirtualFree(MEM_RELEASE)` / Unix `munmap` 归还物理页，回落断言确定（15s 重试窗口容忍分配器延迟）；RSS 回落过程可能经 `Alert` 带（Throttled→Alert→Normal 各一次巡检），`core_rss_alert` 事件计数可能 +1，测试断言不受影响（计数断言在压力段完成）。

### 6.1 security-baseline job 缺 Bun（构建 Mock 失败）

**症状**：M1-08 前置失败项清零后，`Tauri security baseline (M1-08)` job 的「M2 批 2 验证（M2-09）」

**修复**（`.github/workflows/ci.yml`，仅 CI 接线）：

- `security-baseline` job 增加 `oven-sh/setup-bun@v2`（`bun-version: "1.4.2"`，与其余 job 同版本）；
