## 3. P0 语义边界核对（与 D3/D4 一致）

- 写队列临时高水位（≤L2）**不进入** `persist_degraded`；两者解除路径不共用（场景 4 vs 6）；
- 磁盘满注入无环境变量钩子：经 `FakeJournal`（`SQLITE_FULL` code 13）与真实库写队列关闭两类注入；
  空间护栏经 `StartupSelfCheckReport::failing_space`（启动自检路径）；
- 「写队列积压自动回落」与「持久化失败恢复」分别断言，不混淆。
