# Aether M9-14 / G8 发布说明（Electron 默认；Tauri 退役）

| 项 | 内容 |
|---|---|
| 版本 | M9-14 / G8（计划 v0.7，设计 v1.29） |
| 日期 | 2026-11-03 |
| 适用 | Windows MSI、macOS per-arch DMG、Linux deb/AppImage |
| 结论 | Electron 为默认构建/发布壳；`crates/aether-tauri` 已退役；**无 Tauri 回退包** |

## 1. 默认壳切换

- 开发：`pnpm dev:desktop`（Electron main/preload + Vite renderer + `aetherd`）。
- 打包：`pnpm package:desktop`（electron-builder：Windows MSI / macOS DMG / Linux deb+AppImage）。
- 冒烟：`pnpm smoke:installer`（Windows）、`pnpm smoke:installer:macos`、`pnpm smoke:installer:linux`。
- Tauri 命令/构建/安装器不再产出；`cargo test --workspace` 不再包含 `aether-tauri`。
- 迁移期 `packages/protocol/src/bindings.ts` 与 `scripts/ci/bindings.mjs` 已删除；类型契约由
  `pnpm --filter @aether/protocol check` 校验（63/59/4、32+9、diff=0）。

## 2. 旧内测包手工卸载（必须）

曾安装 Tauri 内测构建的机器**没有 MSI 升级链/回退包**，请先手工卸载旧包：

1. 关闭所有 Aether 窗口/进程（含残留 `aether-tauri`/旧核心进程）。
2. Windows：设置 → 应用 → 已安装的应用 → 卸载 “Aether”（或旧 Tauri 内测包名称）。
   macOS：将旧 `Aether.app` 拖入废纸篓；如安装过 DMG，弹出并删除挂载卷。
3. 确认旧安装目录已移除；**不要删除数据目录**（见 §3）。
4. 安装本版 Electron 构建；首启创建会话并验证发送/中断。
5. 不得与旧 Tauri 包双安装/双开同一数据目录；daemon 的 `.aetherd.lock` OS 独占锁会以
   `data_dir_locked` 拒绝第二个核心。

详细步骤与历史包说明见 `docs/M9-11-旧包手工卸载说明.md`。

## 3. 数据目录

- 默认数据目录（Windows）：`%APPDATA%\Aether`；macOS：`~/Library/Application Support/Aether`；
  Linux：`$XDG_DATA_HOME/aether`（或 `~/.local/share/aether`）。
- **卸载不删除数据目录**；升级/切换壳前后建议先做一次备份（`backup_create`）。
- 数据目录必须位于本地磁盘（A4）：不要放在 OneDrive/iCloud/网络盘；否则以 `startup_blocked`
  拒绝并提示。
- 同一数据目录同时只允许一个 daemon；双开会得到 `data_dir_locked`。
- 旧库可直接打开；M9 不新增迁移，schema 仍为 0001–0009。

## 4. Keychain / 密钥

- 供应商密钥只存 OS Keychain（macOS Keychain / Windows Credential Manager / Linux Secret Service），
  配置只存 `keychain://` 引用；日志、诊断包、导出文件不含密钥。
- 从旧内测包升级时，Keychain 条目通常保留；首次启动会做 preflight：
  - 可读：正常使用；
  - 不可读/需重新授权：按 S-13 提示重新授权或输入口令（A3 降级文件模式）；
  - **不要手工删除 Keychain 条目**，否则供应商密钥需重新录入。
- macOS 若出现 Keychain 授权弹窗，请允许 Aether 访问自身条目；拒绝授权会进入 S-13 流程。
- 应用级 Credential Broker token 每次启动随机生成，不落盘、不写日志。

## 5. 签名与发布策略（ADR-030）

- Windows：有证书时签名 + RFC3161 时间戳；无证书时**允许 unsigned 发布**，但必须记录
  `unsigned_release=true`、SHA256，并在发布页给出 SmartScreen 指引；不得声称已签名。
- macOS：**公开发布必须** Developer ID 签名 + 公证 + `stapler` 验证；缺失**仅阻塞 macOS 公开发布**，不阻塞 M9/M10（ADR-030 v0.2）。未取得授权时不得发布 DMG；人工授权步骤见 `docs/M9-14-macOS-签名授权方案.md`。
- Linux：构建 + CI 冒烟，不纳入签名发布门禁；发布签名/分发在 P2 之后另立计划。
- 哈希：`dist-out/SHA256SUMS.txt`；构建清单：`dist-out/m9-11-build-manifest.json`。

## 6. 失败处理（无回退包）

- 任一 G4–G7 门禁失败：**停止发布并修复**，可保留上一 Electron 候选构建；**不回装 Tauri**。
- 演练与决策记录：`docs/M9-14-失败处理演练报告.md`、`docs/M9-Gate-G8-报告.md`。
- 当前 **macOS 公开发布**待人工授权：Developer ID/公证密钥未就绪（`macos_release_pending`）；
  按 ADR-030 v0.2 **不阻塞 M9/M10**。取得密钥并按 `docs/M9-14-macOS-签名授权方案.md` 完成
  签名/公证/`stapler` 验证后方可发布 macOS DMG。

## 7. 安装/卸载冒烟

```powershell
pnpm package:desktop
pnpm smoke:installer
# 或 test 变体（含 Mock 适配器，仅测试）：
pnpm package:desktop:test
pnpm smoke:installer --variant test
```

卸载后确认：应用目录移除、数据目录保留、重新安装后可读旧数据；不得残留旧 Tauri 安装。
