## 1. DoD 逐条证据

### DoD1 等待态写入（置位/回程守卫 + 单一写者 + 静态检查）

**验证方式**：集成测试 + 脚本静态断言。

**实际运行命令与输出**（节选，全量见 §2）：

```text
$ cargo test -p aether-control --test m3_12_waiting_state -- --nocapture
running 5 tests
[m3-12 DoD1] 状态转移序列 = [("creating", "idle"), ("idle", "running"), ("running", "waiting_permission"), ("waiting_permission", "running"), ("running", "idle")]
test dod1_mark_clear_guards_and_status_events ... ok
...
test result: ok. 5 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out
```

断言内容：
- `idle` 时 `mark_waiting_permission` / `clear_waiting_permission` 均返回 `false`（no-op）且不落行、不发事件；
- `running` → ask → 置位 `running → waiting_permission`；已在等待重复置位 no-op；allow 决议 → 回程 `waiting_permission → running`；已在 running 重复回程 no-op；
- 非 running 的 ask（run 终态后）不改写会话状态；
- 等待态方向边恰好各一次、`from/to` 精确匹配，全部转移经 `session_transition_allowed`（19 边白名单）校验合法。

**静态检查（verify 脚本第 6 节，实际 PASS）**：去注释后 `permission.rs` 不得含 `UpdateSessionStatus` / `InsertSession` / `SessionManager` / `SessionStatus`；`lifecycle.rs` 含 `mark_waiting_permission` / `clear_waiting_permission` / 观察者实现 / `can_transition` 守卫；`lib.rs` 含 `set_pending_observer`。

### DoD2 回程合法性（allow / deny / 超时 / 取消 + run 失败收口；并发幂等）

**实际输出**：

```text
[m3-12 DoD2 cancel] 状态转移序列 = [("creating","idle"),("idle","running"),("running","waiting_permission"),("waiting_permission","running"),("running","idle")]
[m3-12 DoD2 deny/timeout] 状态转移序列 = [("creating","idle"),("idle","running"),("running","waiting_permission"),("waiting_permission","running"),("running","waiting_permission"),("waiting_permission","running")]
[m3-12 DoD2 failure] 状态转移序列 = [("creating","idle"),("idle","running"),("running","waiting_permission"),("waiting_permission","running"),("running","idle")]
```

断言内容：
- deny：`resolve(Deny)` → 回程 running；
- 超时：`ManualClock` +300s → `sweep_timeouts_once()` 返回票据 → 回程 running；已摘除票据再次 sweep 为空（不产生第二次回程）；
- 取消：`request_cancellable` 绑定在途 run 令牌 + `interrupt` → 等待者收 deny（非超时）→ 合法回程后 run cancelled 收口 idle；
- run 失败：注入 `ExecutorOutcome::Failed` → 失败收口经既有 settle（`waiting_permission → running → idle`）；迟到决议命中 idle 回程守卫 → **零新增 `session.status_changed`**（前后事件序列相等断言）。

[m3-12 DoD3] 重启 no-op；状态转移序列 = [("creating", "idle")]
test dod3_restore_pending_never_marks_waiting_state ... ok

断言内容：两张 pending 票据经新服务实例 `restore_pending()` 恢复且新管理器会话状态保持 `idle`；决议 A 与超时 B 均命中回程守卫 → 基线（仅 `creating → idle`）与终态事件序列**完全相同**、无任何 `waiting_permission` 边。
