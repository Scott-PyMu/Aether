## 2. 文档侧复核结论

- **真相表**：ADR 与设计同一份 21 行穷尽表 + 未列组合默认 `invalid_value`；覆盖 provider 空/有/失效 × model 空/有效/失效 × send provider/model 有/无；补选并发 `session_busy`、provider 失效优先、UI 优先级均已写入。
- **状态回显**：`model_state`（active/invalid/missing）已覆盖停用/删除/不属于 provider；provider 空时“存在且启用”语义已补齐。
- **旧会话补选**：Claude per-run env；Codex/DSH 空闲/独占锁复制/采用，失败不重建/不持久化；准备成功判定与 run 失败不回滚已写。
- **安全边界**：应用级 token 暂定接受；端点用户输入风险；broker ACL、provider→protocol、CLI 子进程 token 剥离保留。
- **版本链**：设计 v1.24、需求 v0.18、P1 计划 v0.13、UI-UX v0.14、ADR-010 v0.10、AGENTS 已同步；命令面 63/错误码 32/迁移 0009 不变；设置键 9、锚点 20。
