## 4. 失败注入/边界样本

- 路径穿越：`gen-../escape…` → `LayoutInvalid`（`layout::tests::path_traversal_generation_is_rejected`）。
- `shards.json.generation` 字段 → 拒绝（`layout::tests::shards_json_rejects_generation_field`）。
- 备份 manifest 路径绝对/`..`/空段 → `validate_relative_path` 拒绝。
- 加密备份集：逐文件 AEBK（同一密钥/口令盐），manifest 记录密文哈希；恢复逐文件解密到 staging（`m5_03` 8/8）。
- 维护态：备份/恢复设置 `MaintenanceCell`；dispatch 仅放行 `health`/`app_exit`（源码 + 单测；长窗口 UI 证据 M10-10）。
- 备份中写入压力：`backup_under_write_pressure_drains_and_preserves_events`（500 事件写入中备份；drain 后 queue depth=0；恢复后 500 事件保留）。
- 恢复进程 kill：`m10_10_restore_kill`（staging 中 kill；`CURRENT` 不切换；staging 清理；旧 generation 保留）。
- Windows `CURRENT` 替换失败：`current_replacement_failure_keeps_old_pointer`（只读目标替换失败；旧指针保持）。
- WAL 非 0：`m10_10_startup` 严格 sidecar 失效并触发后台检查。
