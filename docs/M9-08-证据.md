## 2. 实现摘要

### 2.1 生成链（单一事实来源）

- `crates/aether-app/src/protocol.rs`（新增）：
  - `AetherEvent`：9 字段事件信封（`v/id/session_id/run_id/runtime_id/seq/ts/type/payload`），
    `from_envelope` 与 `aether_core::EventEnvelope` 同构；
  - `AetherErrorData`：`aether_code` / `business_code?` / `details?`。
- `crates/aether-app/tests/m9_08_protocol.rs`（新增）：
  - `export_protocol_types`（`--ignored`）：specta + `specta-serde::PhasesFormat` +
    BigInt→number 重映射，写 `packages/protocol/src/types.ts`；
  - `aether_event_matches_core_envelope_nine_fields`：事件 9 字段/序列化等价；
  - `aether_error_data_carries_optional_business_code_and_details`：错误形状。
- `scripts/ci/protocol-types.mjs`（新增）：调用上述导出测试 + `git diff --exit-code`。
- `scripts/ci/protocol-client.mjs`（新增）：从 `command-manifest.json` +
  `error_codes.json` 生成 `client.ts`（63 方法、`AetherError`、`onEvent`、preload 信封解包）。
- `scripts/ci/command-manifest.mjs` / `error-codes.mjs`：沿用 M9-04/M9-03 生成器。
- `packages/protocol/src/index.ts`：导出 `types.ts` / `client.ts`，不再导出 `bindings.ts`；
  `packages/protocol/package.json` 的 `generate`/`check` 接入四个生成器（bindings 仍在末尾
  作为迁移期对照）。

### 2.2 renderer 迁移

- 14 个命令面模块（`session/archive/audit/backup/diagnostics/health/permission/presets/
  providers/rules/settings/startup/workspace/artifacts`）全部改为 `client.<method>(...)`；
  入参从 Tauri `{ payload }` 改为内层 DTO（ADR-029 §4.3）。
- `eventBridge.ts`：`listen` → `client.onEvent`；EventStore/`last_seq`/补读不变。
- `backfillSource.ts` / `workspace.ts` / `startup.ts`：错误归一改用
  `tryAetherError` / `aetherErrorCode`（`business_code` 优先、`aether_code` 兜底）。
- `SessionWorkbench.tsx`：`getCurrentWebview().onDragDropEvent` → DOM `drop` +
  `window.aether.pathForFile(file)`（M9-07 preload；坐标仍用 `getBoundingClientRect`）。
- `App.tsx`：移除启动门渲染；Electron main 在 `runStartupSequence` 成功后加载主 UI
  （M9-07），启动快照失败不阻断主界面。
- `health.test.ts` / `startup.test.ts`：mock 从 `@tauri-apps/api/core` 改为
  `@aether/protocol` client。

### 2.3 未改动面

- 63 命令/32 IPC 错误码/9 业务码/9 字段事件/迁移 0001–0009 未改；
- EventEnvelope/附录 B、EventStore 补读、`messages_page` 预算/cursor 未改；
- `packages/protocol/src/bindings.ts` 未手改（生成器复核 `changed=false`）；
- 未新增依赖（`specta-serde`/`specta-util` 已在 Cargo.lock，仅用于导出测试）。
