| 第 1 轮（05:23） | Codex 20/20 PASS；其余全绿（m7_01_hotplug 断言漂移除外，见 §5） | — |

## 4. DoD4：任一运行时失败 → ADR-008 §5 分层处置并记录；门禁前必须全绿

**分层处置机制（P0 基线，M7-05 复验）**：监督器按运行时独立状态机（D5）——单个运行时 `disabled/degraded/start_failed` 仅影响自身，不阻塞其他运行时与核心；对应断言：

```text
PASS  DoD4 aether-tauri m7_01_hotplug（隔离断言：单运行时故障不阻塞其他）
  - 禁用 mock 后 codex 仍 ready 且 PID 不变（隔离断言）；
  - mock 在途 run 收口 adapter_disconnected/cli_exit、queued run 收口 adapter_unavailable（recoverable）；
  - 10 次热插拔循环无孤儿进程/句柄与内存增长受控（同文件用例）。
```

真实冒烟分层记录（本任务执行窗口）：Codex 出现上游慢响应/超窗（§2 flake 表），属**外部网关时延**，门禁未静默豁免——按「记录 → 复跑 → 全绿」闭环；任一运行时在门禁前必须全绿（§6），本任务最终 `verify:m7-05` 22/22 全绿方视为通过。

## 5. 门禁暴露的问题与修复（设计驱动 / 留痕）

1. **`m7_01_hotplug` 断言漂移（E2E 门禁捕获）**：`disable_confirmation_closes_in_flight_runs_and_retry_replays` 断言错误信息含「已禁用」，而 M7-02 会话创建路径已将禁用文案强化为「已被用户禁用（enabled=0）」→ 该用例在 M7-02 之后未被复跑，漂移潜伏。修复：断言改锚定语义稳定子串（`"禁用"` + `"enabled=0"`），不改变 DoD 语义（被禁用运行时仍不可创建会话）；用例 3 连跑全绿。
2. **Codex 真实冒烟慢 run**：见 §2（测量窗口 300s；上游时延 flake 记录；复跑 20/20）。
3. **CI/夜跑接线**：`ci.yml`（push）与 `m4-nightly.yml`（夜跑）均校验 `m7-05` job 存在（静态断言），并归档证据；夜跑真实冒烟以 secrets 自动启用 REQUIRE（缺配置 → 显式 SKIP 行）。
