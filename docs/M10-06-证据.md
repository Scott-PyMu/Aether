## 8. Electron 独立文档（S-00 / S-12 / S-13）的意义与影响

这三个文档不是 React 主界面的一部分，而是 Electron main 在 **React renderer 之前或
无法加载时** 展示的原生窗口页面：

| 文档 | 触发时机 | 作用 | 不本地化的影响 |
|---|---|---|---|
| `electron/startup/`（S-00） | Electron main 启动 `aetherd`、等待 initialize/握手期间 | 显示启动进度；失败时给出重试/诊断入口 | 英文 OS 用户在启动阶段看到中文，但通常仅持续数秒 |
| `electron/fatal/`（S-12） | renderer 加载失败、数据目录锁定/DB 打开失败等致命路径 | 解释阻断原因并给出退出/重试/诊断入口 | 致命错误是用户唯一可见信息，语言不一致会降低可理解性 |
| `electron/keychain/`（S-13） | OS 凭据库 preflight 降级/不可用 | 说明降级风险并让用户选择继续/退出 | 安全相关决策点语言不一致，影响风险告知 |

影响范围：

- 它们 **不读取 `ui.locale`**：此时 settings/DB/renderer 尚未可用，只能使用
  `app.getLocale()`/`navigator.language` 的 OS 语言。
- 它们不属于 `apps/desktop/src/i18n` key 集，因此本次 `verify:m10-06` 的 AST 扫描
  范围是 renderer；这不代表它们永远不会被本地化。
- 若要补齐，建议另立小任务：在 main 侧提供 `electron/i18n.cjs`（zh/en 两套少量文案），
  启动 `BrowserWindow` 前读取 `app.getLocale()` 注入，不依赖后端/settings；不改命令面。
  本任务未实施，以免把 renderer i18n 的 key 体系强耦合到启动门窗口。
