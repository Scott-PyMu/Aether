## 4. 未验证项与限制（如实标注）

1. **真实日历跨日运行**（连续多日夜跑验证补备/排期）不在本任务：本任务以时钟注入（`ManualClock`）+ 首 tick 补备逻辑断言；P1 阶段级夜跑由 M8-01 承接。
2. **加密消费**（`backup.encryption.enabled`、Keychain 主密钥）属 M5-03：本任务产物保持 P0 `.db` 形态（`encrypted=0`），M5-02 **不读取**该键（避免在 M5-03 落地前因「加密不可用」静默停备）；边界见 ADR-020（M5-03 执行方标记为 `backup.encryption.enabled = ADR-020 / M5-03`）。
3. **UI 的 E2E 为组件级（vitest + 注入替身）**，与仓库既有口径一致（M3-04/M3-05）；真实 WebView 冒烟由 M8-01 承接。
4. **诊断包 `backup_auto` 段**：集成夹具 + 静态接线检查覆盖；未跑完整桌面应用导出流（M8-01）。
5. **`backup_list.auto` 状态为进程内运行状态 + `backups` 表成功历史**：重启后 `last_result=success` 由台账推导、`consecutive_failures` 归零（失败告警的持久记录在 `audit_log`，可查）；未新增迁移/settings 键（ADR-020 边界：`0004+` 无备份规划位）。
6. **`git status` 中 `acl-recovery/`、`deepseek_html_V0.0.1.html` 等为工作区既有未跟踪文件**，非本任务产物。
