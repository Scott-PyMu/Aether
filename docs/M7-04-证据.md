**布局落点与语义（DoD3）**：持久化于 settings 键 `ui.layout`（ADR-018 附录 A-6：string，JSON 对象 ≤64KiB，缺省 `"{}"`，迁移影响 = 无）。模型 `{version:1, tabs:[...], active, split}`；`active`/`split` 必须落在 `tabs` 内且互不相同；非字符串/非法 JSON/非对象/版本不符/字段类型非法 → **回退默认布局**（空标签、无分屏）；引用悬空 → 静默归位；首次运行（设置行缺省 `{}`）延续 P0 行为自动打开首个会话，用户显式操作（打开/切换/关闭/分屏）后立即写回。**关闭标签不删除会话**（删除属 M7-07）。
