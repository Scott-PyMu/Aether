## 1. 变更摘要

- **优先级队列**：`GateQueue` 由 FIFO 升级为分数队列
  `score = base_priority + runtime_weight + wait_boost`（升序）；同分
  `queued_at ASC → run_id ASC`；`wait_boost = min(60, floor(wait_ms/10s))`；
  等待 ≥5min 额外 `−100` 并每 run 审计一次 `scheduler.starvation_guard`；
  全局队列上限 64（超限按来源 `storage_backpressure`/`session_busy`，不静默丢弃）。
- **超时/重试**：`session_send.timeout_ms`（1s–24h，缺省 30min）到点先
  interrupt，5s 宽限未收口 → `runs.status='timeout'` + `run.failed`
  （`run_timeout`，可重试）；`max_attempts`（1–5，缺省 1 = 关闭）按
  1s/2s/4s/8s/16s/30s/60s ±20% 抖动创建新 attempt；旧 attempt 终态保留；
  可重试分类 `timeout/run_timeout/run_stream_timeout/adapter_unavailable/
  provider_unreachable/storage_backpressure`；人工 `run_retry` 对
  `provider_auth_failed`/权限拒绝/`invalid_value` 等返回 `invalid_value` +
  `data.retryable=false`。
- **路由**：固定权重不变；同分候选按 `active_runs` 负载 tie-break；
  `degraded` 手动/自动均排除；无候选保持 `no_candidate_runtime`；自动路由审计
  `route.decided` 增负载快照。
- **重启**：`reconcile_interrupted_runs` 保留 `queued` run 并按原
  `queued_at/priority` 重建队列（不丢）；`running` run 收口 `failed`
  （`run_interrupted`），不自动重放。
- **可观测**：`queue_list`（全量/按会话；position/priority/score/queued_at/
  wait_ms/wait_reason）；`health.concurrency_gate` 增
  `queued_by_priority`/`starvation_guard`。
- **UI**：复用 M7-02 `queue-position` 锚点，增 `data-wait-reason` 与等待原因
  文案；`run-retry` 入口不变。

## 3. DoD 逐项结果

### DoD-1 优先级与公平性

- **实现**：`crates/aether-control/src/gate.rs`（`GateWaiter::score`/
  `GateQueue::pop_best`/`position`/`snapshot`/`mark_starvation_guarded`、
  `MAX_QUEUED_GLOBAL`）；`lifecycle.rs`（`send_with_schedule`/`retry_run`/
  `queue_list`/`sweep_starvation_guard`）。
- **公平性**：每会话仍为「1 在途 + 1 等待」（`session_busy`）；全局上限 64；
  `wait_boost` 上限 60；5min guard 每 run 一次审计；优先级不绕过闸门。

## 8. 未决风险/开放问题

1. 自动重试待执行项为进程内内存态：daemon 重启后不自动重放（旧 run 保留终态，
   可人工 `run_retry`）；与 ADR-037「不自动重放」一致。
2. `queue_list` 的 position 为「全局队列 + 会话等待槽」合并排序后的 1 起位置；
   `gate.queued` 仍只计全局队列（两层不重复计数），已在 ADR 口径内。
3. 真实三运行时（Claude/Codex/DSH）未在本任务重跑长时超时/自动重试验收；
   M10-02 的真实交付验证不受影响（本任务未改适配器协议）。
4. `health.concurrency_gate` 的 `api.state` 由 M10-03 顶层 `health.api`
   承载（既有实现），本任务未重复注入；`queued_by_priority`/`starvation_guard`
   已落地。
5. `paused`/终态会话的 `queued` run 在 daemon 重启时不自动派发：按
   `run_interrupted` 收口为可重试失败（保留 ADR-017 暂停门禁，避免绕过暂停/
   终态；用户恢复会话后可 `run_retry`）。
