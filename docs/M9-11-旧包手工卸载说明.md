# M9-11 旧内测包手工卸载说明（Tauri → Electron）

> 适用范围：曾安装 **Tauri 内测构建**（M8-04 及更早）的机器。
> 依据：ADR-029 v0.4 §6 / D-029-10、P2 计划 M9-11 DoD-5。
> 结论：**不提供旧 MSI 升级链，也不提供 Tauri 回退包**；旧包必须**手工卸载**后再安装 Electron 构建。

## 1. 为什么必须手工卸载

- 未发布过旧版本，Windows Installer 升级链不存在；新 MSI 使用**新的 UpgradeCode**，
  不会自动替换旧 Tauri 包（见 `pnpm verify:m9-11` 的「无旧 MSI 升级链」断言）。
- 两套壳共享同一数据目录（Windows `%APPDATA%\Aether`）与 daemon 数据锁
  `<data_dir>/.aetherd.lock`。若旧包仍在，可能出现**双安装/双数据写**风险
  （第二个核心会以 `data_dir_locked` 拒绝启动，但旧壳仍可能先写入）。
- macOS 同理：旧 Tauri `.app` 与新 Electron `.app` 使用同一 bundle id
  `dev.aether.desktop`，必须先把旧应用移入废纸篓。

## 2. 卸载步骤（Windows）

1. 退出 Aether（含托盘/后台进程），确认任务管理器无 `Aether.exe`、`aether-tauri.exe`、
   `aetherd.exe`。
2. 打开「设置 → 应用 → 已安装的应用」，找到旧内测版 **Aether**（发布者/版本为 Tauri 构建），
   选择「卸载」。
   或使用命令行（ProductCode 从注册表
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall` 或
   `HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall` 获取）：

   ```powershell
   msiexec /x "{旧包 ProductCode}" /qn /norestart
   ```

3. 确认旧安装目录已移除（常见为 `C:\Program Files\Aether` 或
   `%LOCALAPPDATA%\Programs\Aether`）；如残留仅手工删除该**程序目录**。
4. **不要删除数据目录** `%APPDATA%\Aether`（数据库、迁移 `0001–0009`、备份、设置、
   审计、供应商密钥引用都在其中）。卸载器不删除数据目录（DoD-4 断言）。
5. 安装新的 Electron 构建：

   ```powershell
   msiexec /i "Aether-<version>-x64.msi" /qn /norestart
   ```

   Windows 发布包按 ADR-030 可为 **unsigned**（无证书）；双击安装时 SmartScreen 提示
   选择「更多信息 → 仍要运行」，并核对 `SHA256SUMS.txt`。macOS 包仍需签名/公证。

6. 首启按正常流程；若出现 **S-13**（Keychain 重新授权/口令降级），按提示操作，
   **不要删除旧凭据条目**（M9-09 §5.4）。

## 3. macOS

1. 退出旧 Aether，将旧 `Aether.app` 移入废纸篓（或 `sudo rm -rf /Applications/Aether.app`）。
2. 保留 `~/Library/Application Support/Aether`（数据目录），不要删除。
3. 挂载新的 per-arch DMG（`Aether-<version>-arm64.dmg` 或 `-x64.dmg`），拖入
   `/Applications`；首次启动按 Gatekeeper 提示操作（签名/公证产物应直接通过）。

## 4. 验收与排查

- 安装前可用 `pnpm smoke:installer` 的预检：脚本枚举已安装的 Aether 产品，若发现旧包会
  **拒绝继续**并提示手工卸载（防止双安装）。
- 安装后确认只有一个 Aether 产品（设置 → 应用；或 `msiexec` 产品枚举）。
- 数据目录/Keychain 兼容性见 `docs/M9-09-证据.md` §5.4 与 `docs/M9-11-证据.md`。
