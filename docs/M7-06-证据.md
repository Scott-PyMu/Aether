## 0.4 实现登记（ADR-024 落地口径）

| 项 | 登记内容 |
|---|---|
| 供应商选择规则 | 运行时 → 类型映射：`claude-code`→`anthropic`、`codex`→`openai`、`deepseek-harness`→`deepseek`；满足映射的**启用** provider 取 `(updated_at, id)` 最大者（确定性）；无命中 → 不注入（官方默认） |

| 失败隔离 | 未接线/读取失败/密钥不可读 → 记诊断并返回空集合（不阻断适配器启动）；`provider_test`/`provider_models_fetch` 无密钥 → `invalid_value`（field=`api_key_ref`），**不发任何请求** |
| 超时常量 | 请求总超时 **10s**、连接超时 **5s**（`PROVIDER_HTTP_TOTAL_TIMEOUT`/`PROVIDER_HTTP_CONNECT_TIMEOUT`；R9） |
| 引用块形态（A-3 冻结） | `<aether-references>` + `- file: <path>` / `- directory: <path>` 清单 + 「以上为随消息附带的文件引用，按需读取」+ `</aether-references>`，空行后接原消息；三运行时共用（adapter-sdk `composePromptWithReferences`）；**核心不读内容、引用不落库、不预授权** |
| DSH provider 键 | `aether-<provider_id>`（前缀保证 YAML 标量以字母开头） |
| DSH 按会话选模型 | `session/new|resume` 的 `configOptions` `model` 项，value 为 `["provider","model"]` JSON 字符串；优先消费映射 provider 命中项，否则首个匹配；无匹配 → 保持默认 + 诊断 |
