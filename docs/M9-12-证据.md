口径说明：

- 权限超时 E2E 使用 `test-hooks` 把 300s 压缩为 **1500ms**；断言 `permissions_pending[].timeout_ms === 1500`，随后审计出现 `permission.timeout`。生产构建不启用 feature，恒为 300s（`boot.rs`）。
- `permission_timeout` 的 `permission-timeout-note` 是 UI 展示值（来自事件投影的 `requestedAt/timeoutMs`），不作为超时门禁断言；门禁断言是 `timeout_ms` + 卡片消失 + `permission.timeout` 审计。
- E2E 使用真实 `aetherd`、真实 SQLite、真实 JSON-RPC；仅运行时适配器为 Mock（ADR-008：Mock 仅测试构建）。
- 证据归档：trace（含截图/快照）、13 张流程截图、`evidence.json`（`attempts` 记录；本次 attempt=1）。

## 8. 本任务发现并修复的缺陷

M9-12 的真实 daemon E2E 首次调用 `audit_query` 时命中 trait 默认 `not_implemented`：

- 根因：`SessionBackend`（外层）与 `DiagnosticsControlBackend`（诊断装饰器）未透传 M6-03 的 `audit_query`/`audit_export`；M9-04 路由矩阵使用脚本化 backend，未覆盖生产装饰器链。
- 修复：两处显式委派到内层 `ArchiveControlBackend`。
- 回归：`crates/aether-daemon/tests/m9_12_regressions.rs`（真实 daemon + 真实存储）：
