## 3. 应用级 E2E（三运行时 + 真 broker + 假 CLI）

测试：`crates/aether-tauri/tests/m7_10_provider_e2e.rs`（`AETHER_M7_10_REQUIRE=1` 下必跑；否则显式 SKIP）。
运行结果：**1 passed**（约 5.9s；Windows 本机）。

### 3.1 三运行时正向与并发

- 三运行时（`claude-code` / `codex` / `deepseek-harness`）分别创建两会话（provider A/B、model A/B）；
- 两会话并发 send，均 `run.completed`；
- Claude CLI env 记录：`ANTHROPIC_API_KEY` = A/B，`ANTHROPIC_BASE_URL` = A/B 显式端点，无 `AETHER_CREDENTIAL_BROKER`；
- Codex：两会话 `CODEX_HOME` 不同；各自 `config.toml` 含不同 `base_url` 且不含密钥值；
- DSH：provider 会话 `DSH_HOME` 位于 `aether-dsh-sessions/<session>` 且互不相同；per-session patch 含各自 base URL；
- 所有适配器 CLI/ACP 子进程 env 中 `AETHER_CREDENTIAL_BROKER` 均为空。

### 3.2 旧会话补选（三运行时）

- 直接插入无 provider/model 的旧会话（保留 `config.native_id`）；
- 首次 `session_send` 携 `provider_id/model`：Claude per-run env；Codex 复制/采用 thread 状态；DSH 复制/采用会话状态；
- 持久化后 `sessions.config.aether.provider_id` / `sessions.model` 正确；
- 原生上下文保留：`recall` 分别返回 `CLAUDE-LEGACY-TOKEN` / `CODEX-LEGACY-TOKEN` / `DSH-LEGACY-TOKEN`；
- 已选会话再传 provider/model → `invalid_value`；
- 后续 send 不带字段可用（持久化生效）。

### 3.3 状态复制约束 / 准备成功 / run 失败

- **仅空闲/无在途 run**：适配器侧再次 `session.create` 时若存在 active run → 拒绝（`session_busy` 语义）；
- **独占锁**：Codex `withSessionLock`、DSH 单会话串行准备；复制/物化失败清理新目录；
- **准备成功判定** = 配置物化 + 原生状态采用 + 适配器 ack；核心在 ack 后才写 `sessions.config`/`model`；
- **run 失败不回滚**：持久化发生在准备 ack 后；run 启动后的失败按失败/重试路径处理（E2E 中断/重试验证）；
- dispose：Codex/DSH per-session 目录清理，legacy 目录不动（E2E/单测断言）。

### 3.4 补选并发 / 只读 / 中断

- 选中会话在途 run + model 被停用 → `session_send.model` 补选返回 **`session_busy`**，消息包含
  「当前任务仍在运行，暂不能补选供应商/模型，请等当前任务结束后重试。」且保留业务码 `session_busy`
  （不复用等待队列满文案）；
- provider 停用后：`session_send`/`run_retry`/`session_resume` 拒绝（只读）；`messages_page` 可读；
  `session_interrupt` 仍可用并取消在途 run；不自动切换 provider；不中止 run 的只读判定优先于并发检查。

### 3.5 密钥轮换

- 同一 provider 两次 run 之间更新 SecretStore 值；
- 第二次 Claude CLI env 记录为 `fake-key-a-rotated`（每次 run 现取、不缓存、不落盘）。

### 3.6 目录查询协议（`provider.catalog.get`）

- `crates/aether-adapters --lib connection::tests::provider_catalog_*` **3 passed**：
  - 并发两个请求 → 目录源仅调用 1 次（coalesce）；响应非机密（无 `api_key`/token）；
  - 参数非法 → `-32602` + `data.aether_code=invalid_value`；内部错误 → `-32603` + `core_not_ready`；
  - 响应 >2MiB → `-32603` 错误帧（不截断、不断连、无效帧计数 0）；
- 目录源：`aether-tauri provider_catalog.rs` 只映射 id/name/type/enabled/endpoints/models；
- **适配器侧使用**：Claude/Codex/DSH 在 `session.create` 与每次 run 前调用 `provider.catalog.get`
  （`catalogClientFactory` 生产接线；单测未注入时不查询），provider 停用/不存在或 model 不归属
  → 本次操作失败（不回退旧快照）；适配器 SDK 请求处理器异步分发（避免双向请求在读循环内
  await 导致响应帧无法读取的死锁）；
- 应用级 E2E 断言目录不含 `api_key`/`fake-key`；
- 目录规模/延迟：本地 E2E 2 providers × 2 models，查询 <5s（实测同一次覆盖内完成；不设外部门槛）。
