## 4. 与 M5-04 的接口约定（G2 链）

- 自动归档（`auto-retention`）与导出（`session-export`/`archive-export`）共用同一 JSONL 格式与写出设施（`crates/aether-store/src/archive.rs`）；M5-04 清理链路在删除前逐批调用 `verify_archive_file` 校验（见 `docs/M5-04-证据.md` DoD3）。
- 归档产物位于数据目录 `archives/`（自动与默认导出）；保留窗口与归档保留解耦（归档不自动删除）。

## 5. 已知边界与后续

1. `verify-archive.mjs` 为逐行解析（字段白名单 + 脱敏扫描），大库归档的哈希校验由 Rust `verify_archive_file` 流式完成（M8-01 可复用）；CLI 未提供 `--fast` 模式（避免弱化默认校验）。
2. ≥1GB 大库抽样为重 IO 可选任务（`AETHER_M5_05_BIG=1`）；未设置时验证入口**显式打印 SKIP 原因**，不静默。
3. 归档加密/压缩与回灌（导入）按 ADR-021 §5 留 P2/P2+，本任务不做。
