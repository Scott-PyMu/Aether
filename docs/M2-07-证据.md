
断言链：

1. `test dod1_panic_isolates_session_and_other_streams_continue`：会话 A 执行器在 future poll 期间
   `panic!` → 看门狗周期 `reap_run_tasks` 经 `JoinError::is_panic()` 捕获（`reaped >= 1`）→
   A 的 run 行 `status=failed` 且 `error=task_panic`；会话 B 的 run 行 `succeeded`；
   会话 A/B 均回 `idle`；
2. **其余会话事件流连续**：广播订阅自会话创建前建立，session B 的 `seq` 集合严格等于
   `1..=len`（无缺口），并观察到 `run.completed`；A 观察到 `run.failed`；
3. `pipeline.health().sequencer_restarts >= 1`（panic 恢复调用 `restart_session`，D4 崩溃恢复路径）；
4. **panic 会话可续聊**：A 再次 `send` 成功完成（`succeeded`），消息数 3（用户 ×2 + 助手续跑终稿 ×1）；
5. `test dod1_panic_promotes_and_respawns_waiting_run`：A 第 2 条 run 在等待队列时第 1 条 panic →
   恢复路径提升等待 run 并**重新 spawn** 同会话任务 → 第 2 条 `succeeded`；执行器调用序与
   run id 顺序一致（run 串行语义不变）。

实现要点（AGENTS §2.3 不适用事件类型变更；事件仍为附录 B `run.failed`）：

- 会话任务经 `JoinSet<()>` spawn，`AbortHandle` 登记进 M2-05 看门狗（取消兜底/dump 语义不变）；
- panic 收割复用既有 1s 看门狗循环（`spawn_background` 任务数仍为 3，不新增后台任务）；
- panic 恢复错误码 `task_panic`（`ErrorInfo.recoverable=true`，UI 可按 D2 人工恢复口径重试）。

## 4. 边界与偏离记录

1. **`JoinSet` 化范围（D2 实现要点部分落地）**：本任务把**会话执行任务**（run 任务，用户代码
   panic 风险最高路径）统一经 `JoinSet` 管理并由 `JoinError` 捕获恢复；`EventPipeline` actor 与
   生命周期层三个后台监听循环仍为既有 `JoinHandle + abort` 形态（M1-05/M2-01 交付），
   其 panic 属核心内部逻辑故障，不在 M2-07 DoD1 断言范围内，登记为后续（M3-01/P1 复查）事项。
2. **`health` 命令由同步改 async**：为支持 E2E「无响应」注入（`AETHER_E2E_HEALTH_STALL_MS`
   在运行时挂起，不阻塞主线程），命令签名改为 `async fn`；生产路径无等待，参数校验/错误码/
   返回契约不变（`ipc_validation`/`health_command` 回归全绿）。备选（拦截前端
   `__TAURI_INTERNALS__.invoke`）不可行：Tauri 以不可写属性定义该函数。
3. **RSS 告警事件承载会话**：附录 B 无专用资源事件类型（不得自造），告警以 `error` 事件
   （`core_rss_alert`/`core_rss_throttle`）承载于管线最近一次事件来源会话（`default_origin`，
   与 D4 降级通知同口径）；无任何会话时仅 `tracing` + `health` 呈现，不产生事件。
4. **限流窗口常量级调参**：`RSS_THROTTLE_DELTA_INTERVAL = 256ms`（默认 16ms 的 16 倍；
   D8 L1/L2 背压窗口为 64ms），取「原窗口与新窗口较大者」，不缩短既有窗口；在途缓冲
   `relax_deadline` 同步放宽。该调参记录于本证据（AGENTS §3 允许）。
5. **RSS 回落语义**：等级单调按采样回落重置（`Alert → Normal` 无事件，再次越限可重新告警，
   与 M1-10 适配器资源监视「回落复位」一致）；P0 不自动杀进程（D2：巡检告警 + delta 限流）。
6. **生产 `health.runtimes` 由 `null` 变 `[]`**：监督器摘要接线后，正常启动返回已接线空数组；
   `null` 保留给监督器台账初始化失败与启动失败降级后端（诚实状态）。两者均为 ADR-007
   契约合法取值，`health_command` 既有 `null`/`[]` 用例与新增映射用例全绿。
7. **依赖新增（两条边）**：`sysinfo` 与 `tracing-subscriber` 均已在 `Cargo.lock`（分别由
   aether-adapters 与 aether-control dev 使用），本次仅新增运行期边；许可证扫描与
   `cargo deny` 通过，无 GPL/AGPL/BUSL。
8. **M3-05 衔接**：日志汇聚端 `export_text`/`global_sink` 与 `TaskDump`、`ShutdownReport`、
   `CheckpointReport` 等诊断源并列，供 M3-05 诊断包整合；本任务不实现诊断包导出命令
   （`export_diagnostics` 归 M3-05）。
9. **降级态「发送入口禁用」归 M3-03/M3-06**：DoD5 括注明确该联动由 M3-03（权限中心/状态面板）
   与 M3-06（崩溃恢复体验）落地；M2-07 交付两态横幅与 `storage_state` 前端状态（`HealthMonitor`
   已暴露 `degraded`），发送入口禁用不在本任务范围。
