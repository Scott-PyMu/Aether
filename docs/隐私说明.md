# 隐私说明（P0）

Aether 是本地优先的桌面应用：**无账号、无云同步、不做遥测**。

## 1. 数据存储位置

| 数据 | 位置 | 说明 |
|---|---|---|
| 会话/消息/事件/权限/审计 | 本机数据目录 `aether.db`（SQLite + WAL） | 默认 `%APPDATA%\Aether`（Windows）/ `~/Library/Application Support/Aether`（macOS）；可在启动迁移到本地磁盘其他目录（同步盘/网盘会被拒绝） |
| 日志 | 数据目录 `logs/aether.log`（环形 + 文件） | 诊断与容量巡检用 |
| 备份 | 数据目录 `backups/`（保留 10）或用户选择的外部目录 | 手动触发；VACUUM INTO 快照 |
| 附件/引用 | `artifacts/` 目录（仅路径入库） | 附件数据体不写入数据库、不进入线协议 |
| 密钥（模型 API Key 等） | OS 凭据库（Keychain / Credential Manager / Secret Service） | 配置只保存 `keychain://` 引用；凭据库不可用时降级为加密文件（UI 明示安全级别） |

## 2. 网络流向

- 应用本体不发起遥测/更新检查/远程加载；UI 不允许远程内容进入主界面
  （CSP `default-src 'self'`、`withGlobalTauri:false`、外链转交系统浏览器）。
- 模型调用由各适配器在其进程内驱动对应运行时完成；**请求内容只发往你在
  供应商/运行时配置中指定的端点**。适配器出站不受权限门约束（信任边界，P3 沙箱前已知）。
- P0「测试连接」不发起网络请求（toast 提示 P1 开放）。

## 3. 诊断包与脱敏

- 诊断包在导出前统一脱敏：`sk-*`、`eyJ*`（JWT）、PEM 私钥模式 0 命中；
- 诊断包包含：日志汇聚、库摘要、健康状态、安全级别、任务 dump；
  **不含**密钥、消息正文以外的会话内容与可识别个人信息不导出（消息正文仅随数据库本体保存在本机）；
- 导出选择外部路径时做可写与空间检查（≥ 当前 `db+wal` ×1.2）。

## 4. 权限与审批

- 所有经线协议上报的工具调用 100% 经权限网关：工作区内读放行、写询问
  （300s 超时自动拒绝并审计）、工作区外写入拒绝、`exec`/`net` 在 P0 固定 deny；
- 每次请求/决议进入最小审计集（会话生命周期、权限决议、适配器状态变化）。
  完整 Agent 操作审计（查询/导出/哈希链）不属于 P0。

## 5. 你的数据你的控制

- 全部数据在本机库文件中，可随时备份/导出/删除（删除数据目录即彻底清除；
  密钥需同时在系统凭据库删除）；
- 卸载应用不会自动删除数据目录（避免误删），需要时手动清理。
