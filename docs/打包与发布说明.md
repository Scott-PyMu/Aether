# 打包与发布说明（M4-05）

## 1. 产物与工具链

| 项 | 说明 |
|---|---|
| 安装器 | Windows MSI（WiX）/ macOS DMG；由 Tauri bundler 产出（`scripts/ci/build-desktop-installer.mjs`） |
| 编排 | cargo-dist 生成 release/GitHub Release 编排与源码归档；安装器由 `release-desktop-installers.yml` 附加到同一 Release（ADR-001：cargo-dist 不生成安装器） |
| 运行时注册包 | `scripts/ci/build-runtime-bundles.mjs` 生成三官方适配器单文件 + `runtimes.json`（ADR-015 schema）+ `digests.json`，经 `bundle.resources` 进入安装产物 |
| 测试构建 | `AETHER_BUNDLE_MOCK=1` 额外包含 Mock 适配器（仅测试；selftest/安装冒烟用） |
| 哈希 | `dist-out/SHA256SUMS.txt`（`scripts/ci/hash-installers.mjs`；签名后刷新） |

## 2. WebView2（Windows）

- `bundle.windows.webviewInstallMode = embedBootstrapper`：MSI 内嵌 WebView2
  Bootstrapper，无 WebView2 的机器安装时自动引导安装，无需用户手工下载；
- 无网络环境：Bootstrapper 无法下载时可使用 Evergreen Standalone 安装包离线部署，
  或在已有 Edge WebView2 Runtime 的机器上安装。

## 3. 签名与公证（MVP 允许空签）

### Windows（signtool）

未配置证书时流水线输出说明并继续（空签可执行）：

- 用户侧提示：SmartScreen 可能拦截，选择「更多信息 → 仍要运行」；企业分发建议签名；
- 配置签名：在仓库 Secrets 增加 `WINDOWS_CERT_BASE64`（PFX 的 Base64）与
  `WINDOWS_CERT_PASSWORD`；流水线自动执行 `signtool sign /fd SHA256 /tr ... && signtool verify`。

### macOS（notarytool）

未配置凭据时流水线输出说明并继续：

- 用户侧提示：首次打开需「右键 → 打开」或在「系统设置 → 隐私与安全性」允许；
  分发给第三方建议公证；
- 配置公证：Secrets 增加 `MACOS_NOTARY_APPLE_ID` / `MACOS_NOTARY_TEAM_ID` /
  `MACOS_NOTARY_PASSWORD`；流水线执行 `xcrun notarytool submit ... --wait`。

## 4. 干净环境冒烟（M4-05 DoD1）

1. `node scripts/test/m4-05/verify-m4-05.mjs --with-installer`（本机 / CI Windows）：
   构建发布形态 MSI（三官方、无 Mock）→ 记录 SHA256 → `msiexec /a` 管理式解包 →
   注册清单恰为三官方 + `--aether-diagnostics` 首启自检；随后构建 debug 测试 MSI
   （`AETHER_BUNDLE_MOCK=1 --debug`）→ 解包 → 探针驱动会话闭环 + 内联权限回环；
2. 真实干净虚拟机（推荐发布前人工执行一遍，作为发布检查项）：
   - 全新 Windows 11 快照（无 Node/无开发工具、无 WebView2）；
   - 安装 MSI → 首启自检通过 → 新建会话（使用已安装的运行时）→ 完成一次问答；
   - 记录版本、哈希与耗时，归档到发布检查记录（命名见 ADR-013 §6-5）。

> WiX 工具链（Windows MSI 构建依赖）：Tauri bundler 首次构建会在线下载 WiX 3.14；
> 离线/慢网环境可预下载 `wix314-binaries.zip`（sha256 `6ac824e1…`，见 Tauri 内嵌期望值）
> 并解压到 `%LOCALAPPDATA%\tauri\WixTools314` 后构建。

## 5. 产物校验

```powershell
Get-FileHash dist-out\*.msi -Algorithm SHA256   # 与 SHA256SUMS.txt 对照
```

发布检查清单：MSI/DMG 产出、哈希一致、安装冒烟通过、签名/空签说明就绪、
SBOM 归档（CI `sbom-spdx` artifact + `docs/evidence/m4-06/dependency-inventory.json`）。
