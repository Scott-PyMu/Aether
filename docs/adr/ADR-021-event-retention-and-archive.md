## 1. 背景

- P0：事件全量保留 + 每小时容量巡检（2GB 警告 / 5GB 强烈提示）；无清理、无归档（§4#14、D13）。
- P1：事件保留/归档（DS-04 归档路径）+ 导出会话 JSONL（§5 P1）；DoD 约束：超窗 delta 清理、控制事件与审计相关保留、清理前归档（失败跳过）、阈值联动「策略启停」、补读边界、空间回收证据、无长事务（单事务 <500ms）；`audit_log` 不被策略静默删除（M6-03 DoD5）。
- 需定界（P1 计划 §10 待确认 5）：可滚动事件范围、归档保留时长、清理动作（逻辑删除 vs 物理回收）。
- 锚点：UI-UX §8#16 容量「一键归档」按钮（P0 仅占位）+ §7.3 新锚点 `archive`（产品裁定，2026-10-09）。

## 2. 决策

### 2.1 核心决策（五段式）

- **决策**：
  1. **可清理范围（白名单）**：仅 `message.delta` / `usage` / `log` 三类超窗事件可清理；**其余事件类型（`session.*`、`run.*`、`message.completed`、`tool.call_*`、`permission.*`、`runtime.status_changed`、`error`）不清理**（控制事件与审计相关信息保留；tool 调用保留以满足 Agent 操作审计面）。
  2. **保留窗口**：`events.retention.days`（**缺省 30**，可配 7–365）；清理游标 = 事件 `ts`；窗口按批（见 2.1-4）物理删除。
  3. **策略启停（阈值联动）**：`events.retention.enabled` **缺省 `false`**；触发规则：
     - 库 >2GB（警告档）→ 横幅提示「可开启保留策略」，用户一键开启；
     - 事件增长 >500MB/月（周采样）→ **自动置 `true`**（审计 `retention.auto_armed` + 通知）；
     - 库 >5GB（强烈提示档）→ **自动置 `true`** + 强提示（含一键归档入口 `archive`）。
  4. **清理前归档（强制）**：每批删除前，将待删行按 JSONL 追加写入归档文件（附录 A-2 格式 + manifest）；**归档写入/校验失败 → 该批跳过清理**（记录失败计数并告警）；归档保留时长与清理窗口解耦（归档默认随保留策略保留，容量不足时提示用户手动清理，**不自动删除归档**）。
  5. **写入纪律**：批大小 ≤5000 行/事务，批间 yield（`tokio::task::yield_now` 等价），**单事务 <500ms**（D3 口径回归）；清理任务与巡检同频（每小时）限速执行。
  6. **补读与恢复**：`messages_page` 契约不变（ADR-009）；已清理 delta 与线上丢弃 delta 同构（`gap` 可补读语义不变），**不新增错误码与响应字段**；`message.completed` 保留使历史会话完整可读；`last_seq` 补读不受影响（缺口 >10k 的既有路径不变）。
  7. **审计联动（不动 `audit_log`）**：保留任务只触碰 `events` 表；`audit_log` 不清理、不级联（M6-03 DoD5 断言；审计保留策略与哈希链 P3）。
  8. **导出与归档导出（命令语义；命令已由 ADR-018 登记）**：
     - `session_export`：单会话 JSONL（`sessions` 行 + `messages` 终稿 + 该会话 `events` 按 seq 升序）+ manifest；外部路径（选择器 + 可写 + 空间检查，M3-04 同口径）；脱敏 0 命中；原子写（临时文件 + rename）。
     - `archive_export`（= 容量「一键归档」）：全库归档 JSONL（`events` 全量 + `messages` 全稿 + `sessions`/`runs` 摘要）+ manifest；同路径/脱敏/原子写口径；产物可被 M5-04 归档链路消费（同格式）。
  9. **指标**：清理条数/释放空间/归档失败计数入诊断包（M3-05 扩展）。
- **实现要点**：
  1. 设置键（M5-01 DoD5②）：`events.retention.enabled` / `events.retention.days`（附录 A-1）。
  2. 清理任务：由 M5-04 实现（后台；读连接读取待删 id 批 → 写归档 → 单写队列提交 DELETE ≥ 确认归档成功）；空间回收证据记录 `db+wal` 前后值。
  3. 归档目录：数据目录下 `archives/`（自动归档）；用户导出目标由选择器决定；文件命名 `events-archive-<yyyymmdd>.jsonl` / `aether-archive-<ts>.jsonl` / `session-<id>-<ts>.jsonl`。
  4. UI：设置页「备份与保留」区（锚点 `settings-retention`，ADR-014 已登记）；容量横幅「一键归档」（锚点 `archive`，本批次登记）；导出入口（会话菜单/备份页）。
  5. 大库抽样：M5-05 DoD2 含 ≥1GB 大库抽样（行数/哈希与库内一致）、kill 中断不留半成品。
- **主要风险**：清理误删（范围白名单写错）；归档与删除之间崩溃（半清理）；归档文件本身丢失导致「已清理不可回溯」；阈值自动启停的意外触发；大库导出内存峰值；导出内容含密钥（脱敏遗漏）。
- **缓解措施**：白名单常量 + 类型断言测试；「先归档（落盘 + fsync）后删除」顺序 + 归档 manifest（行数与 sha256）使半清理可检测；归档目录纳入诊断包容量统计；阈值触发写审计并可在设置页看到状态；导出走流式读写（1MiB 有界缓冲，M3-04 先例）不整库入内存；脱敏扫描 0 命中为交付门（M5-05 DoD3）。
- **失效条件**：保留策略造成**不可补读且无归档可回溯**（归档与删除不一致）→ 立即停用清理并另立 ADR；出现 `audit_log` 被清理 → 停用清理并复查（严重违规）；阈值自动启停误触发两次以上 → 降级为纯手动开关。

### 2.2 明确不做（P1 边界）

- 不做事件分库（D3 失效路径，M5-06 已按 R16 延后 P2，P1-A09 条件 ADR）；
- 不做归档文件的自动压缩/加密（P1 保持明文 JSONL + 用户自管；加密归档需求另立 ADR）；
- 不做 `events` 的逻辑删除（无 `deleted_at` 列；物理删除 + 归档先行）；
- 不做归档回灌（import）——P2 DS-04 完整导入。

## 6. 回退条件

1. **本 ADR 被否决** → M5-04/M5-05 撤回；事件维持全量保留 + 容量巡检；`session_export`/`archive_export` 命令与锚点 `archive` 撤回。

3. **归档失败却发生删除** → 按严重缺陷处理，回归「先归档后删除」断言；修复前禁止清理。
4. **阈值联动误报** → 降级纯手动；阈值只做提示不做启停（修订本 ADR）。
5. **大库导出性能不达标或内存失控** → 停止导出入口并复审流式实现；不得放宽 DoD。

## 附录 A：设置键 / 归档格式 / 指标登记

**A-1 设置键增行（M5-01 DoD5②）**

| 键名 | 类型 | 缺省值 | 语义 | 迁移影响 |
|---|---|---|---|---|
| `events.retention.enabled` | bool | `false` | 事件保留策略开关；2GB 提示、增长 >500MB/月或 >5GB 时自动置 `true`（审计 `retention.auto_armed`） | 无（settings KV） |
| `events.retention.days` | int（7–365） | `30` | 保留窗口（天）；仅 `message.delta`/`usage`/`log` 超窗清理 | 无 |

**A-2 归档 JSONL 格式（自动归档与导出共用）**

```jsonl
{"v":1,"kind":"manifest","created_at":<epoch_ms>,"source":"auto-retention|session-export|archive-export","session_id":"<ULID|null>","rows":<n>,"sha256":"<payload 行内容 sha256>"}
{"v":1,"kind":"session","...sessions 行字段（脱敏后）}
{"v":1,"kind":"message","session_id":"...","id":"...","role":"...","content":"...","seq":<n>,"ts":<ms>}
{"v":1,"kind":"event","id":"...","session_id":"...","run_id":"...","runtime_id":"...","seq":<n>,"ts":<ms>,"type":"...","payload":{...},"v":1}
```

- manifest 为首行；`sha256` = 后续各行拼接内容的 sha256（行尾 `\n` 归一）。
- 校验工具：`scripts/test/m5-05/verify-archive.mjs`（行数/哈希/字段白名单/脱敏扫描）。
- 脱敏：`sk-`/`eyJ`/PEM 模式 0 命中；`api_key_ref` 原样导出（D10），密钥本体绝不出现。

**A-3 指标（诊断包扩展）**

| 指标 | 说明 |
|---|---|
| `retention.cleaned_rows` / `retention.freed_bytes` | 上次清理条数/释放空间（db+wal 前后差值） |
| `retention.archive_failures` | 归档失败次数（失败即跳过清理） |
| `retention.auto_armed` | 阈值自动启用记录（最近一次） |
| `export.rows` / `export.bytes` / `export.sha256_ok` | 最近一次导出指标 |

**A-4 增长阈值口径**

- 「增长 >500MB/月」= 过去 30 天 `db+wal` 字节差（周采样，取最近 4 周拟合直线斜率 ×30 天）；口径与脚本参数记录于 M5-04 任务证据。
