## 1. 背景

- M3-03 遗留项 1：D9 要求会话等待期间置 `waiting_permission`，但 M2-10/M3-03 的 DoD 均不含该写入；权限服务不写会话状态（M2-05 证据 §4.5）；UI 仅渲染状态标签，会话列表**无分组结构**。
- 首轮评审（2026-09-28）裁定：单列 **M3-12**（不回挂 M3-08；M3-08 仅保留执行器权限网关接线）；设计文档不升版；计划结构变更以登记型 ADR 承载；分组 UI 与 UI-UX §7.3 锚点登记显式纳入 M3-12；真实 WebView 内联回环 E2E 归 M4-05；旧归属以注记更正；并发按展示口径读法。
- 复审（2026-09-28）裁定：R0 形式定为 **ADR-011**（不再考虑书面豁免）；M3-12 DoD6 改为生产组合路径集成 E2E；并发口径书面落定并追认；M3-12 量级初判 M；分组锚点命名由草案给定。
