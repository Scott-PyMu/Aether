## 1. 交付物清单

### 1.1 核心实现

| 文件 | 变更 |
|---|---|
| `crates/aether-security/src/backup_crypto.rs`（新增，~660 行含单测） | **DoD1/2/3/4 核心**：`AEBK1` 产物格式（magic/version/flags/salt/nonce/来源 id/生成时间；头字节即 AAD，单一 16B AEAD tag）；**流式** XChaCha20-Poly1305（1 MiB 分块；与 `chacha20poly1305` 参考实现逐字节对拍）；主密钥（`keychain://aether/backup/master`，32B 随机，hex 存储，首次生成/复用/损坏拒绝）；口令派生（Argon2id m=64MiB,t=3,p=1 + 16B 随机盐）；`inspect`/`is_encrypted` 产物探测 |
| `crates/aether-security/Cargo.toml` + `src/lib.rs` | 直依赖 `chacha20 0.9.1` / `poly1305 0.8.0`（均为既有传递依赖，版本锁定于 Cargo.lock，不引入新 crate）；dev 依赖 `tempfile 3`；模块导出 |
| `crates/aether-store/src/backup.rs` | `create_backup_staging`（VACUUM INTO + quick_check + schema 校验 + fsync，不 rename；加密路径复用）；`.aebk` 命名（`backup_file_name_for_with_extension`）；`cleanup_restore_candidates`（解密候选残留清理，保留待处理日志引用项） |
| `crates/aether-tauri/src/backup_auto.rs` | **DoD2/3 执行路径**：`BackupEncryption`（None/Keychain/Passphrase）；`execute_backup` 暂存 →（加密开启时）流式加密 → 原子 rename；**密钥不可用 → 失败并告警（`backup_key_unavailable`），禁止静默降级为明文**；失败路径同步清理明文暂存（测试捕获并修复）；自动备份设置增 `encryption_enabled`（`backup.encryption.enabled` 缺省 `true`）；`status()` 增 `encryption_enabled`/`encryption_key_available`（诊断段） |
| `crates/aether-tauri/src/backup_control.rs` | **DoD2/3/4 命令面**：`backup_create` 按设置/口令选择加密模式；`backup_restore` 加密产物路径（头解析 → 来源 id 交叉校验 → 口令/主密钥解密 → 明文候选 `.restore-cand-*` → 第 2 步校验 → 现场日志）；`boot_apply_pending_restore` 启动清理历史候选并删除已消费候选；业务码 `backup_key_unavailable`/`backup_decrypt_failed`/`backup_passphrase_required`/`backup_encrypt_failed` |
| `crates/aether-tauri/src/ipc/dto.rs` + `ipc/path.rs` + `ipc/validate.rs` | `BackupCreateRequest`/`BackupRestoreRequest` 可选 `passphrase`（非空 / ≤1024 字符 / 无控制字符；`passphrase_value()` 包装为 `SecretValue`）；外部恢复候选接受 `.db`/`.aebk`（`validate_external_backup_candidate`） |
| `crates/aether-tauri/src/lib.rs` | 组合根：`boot_secret_store` 上提，备份与供应商共享同一密钥存储实例（keyring 自检一次；降级启动不探测） |
