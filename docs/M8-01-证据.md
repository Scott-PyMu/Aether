### 2.4 口径说明（不静默扩大/缩小 DoD）

- **分层口径**（沿用 P0 M4-01/02/03 先例）：任务级测试验证单点行为，M8-01 验证「端到端脚本化执行稳定 + 三段证据归档」；M8-01 不重复实现断言。
- **保留清理中断/归档失败**：以 M5-04 的失败注入语义覆盖「归档失败 → 跳过清理 + 审计 + 零删除」，并以 `DeleteEventsByIds` 单事务（5000 行精确行集、<500ms）覆盖「中断不产生部分删除」；不含进程级 kill 注入（该层面由 P0 T4 kill -9 数据完整性场景与 M5-03 恢复故障注入承担，见 §3）。
- **热插拔中途崩溃**：以「在途 run 期间禁用/终止（进程树回收、连接断连）」为故障面（M7-01 DoD2）+ 10 次循环无孤儿（DoD4）；外部强杀崩溃（T5a）由 P0 30 场景 `runtime-crash` 在同一次夜跑中回归（§3），不重复计入 DoD1。
- **暂停死锁**：以「受控中断 + 下发失败 best-effort + 等待槽保留 + 看门狗不适用 + resume 重放」组合覆盖无死锁语义；用例本身在超时内完成（失败即超时断言）。
- **供应商连通性**：本地 HTTP 桩（无外部凭证；ADR-024），`real_https_tls_path_provider_test` 为 opt-in 真实网络用例，未在本夜跑启用（显式不适用，见 §8）。
