### A. `messages_page` 真实后端

`crates/aether-tauri/src/session_backend.rs`（`IpcBackend::messages_page`；响应契约见
ADR-009 决策 1 / 附录 A）：

```
$ cargo test -p aether-tauri --test m3_02_session_backend -- --nocapture
running 6 tests
test default_gap_limit_matches_core_constant ... ok
test messages_page_latest_returns_tail_ascending_and_option_shape ... ok
test messages_page_pages_backfill_latest_and_guards_gap ... ok
test messages_page_requires_read_pool ... ok
test session_create_persists_model_and_send_interrupt_dispose_are_wired ... ok
test runtimes_list_reports_registry_and_requires_supervisor ... ok
test result: ok. 6 passed; 0 failed; 0 ignored; 0 measured; 0 filtered out; finished in 0.45s
```

语义（响应 `{session_id, last_seq?, max_seq, events, messages?, complete}`；ADR-009 登记）：

| 请求 | 行为 |
|---|---|
| `last_seq: Some(n)` | 读 **events 表** `seq > n`（升序，≤limit）；缺口 `max_seq-n > 10k` → `readback_gap_too_large`（同码透传，不返回事件）；`complete = 末条 seq == max_seq` **或 `n >= max_seq`**（越过最新 → `events=[]`、`complete=true`）；`messages` 字段省略 |
| `last_seq` 缺省 | 最近一页：`events` 取尾部 limit 条（升序，`ReadPool::events_latest`）；`messages` 取 `messages` 表**尾部** limit 条（升序，`ReadPool::messages_latest`；无消息为 `[]`，字段存在）；`complete=true` |
| 未接线读连接池 | `core_not_ready` |

**尾部语义修订（2026-09-23 复核 P0-1）**：`ReadPool::messages_page(session_id, None, limit)`
为「从会话起点读」（M2-01 已交付语义，未改）；最近一页改调新增
`ReadPool::messages_latest`（`ORDER BY seq DESC LIMIT` + reverse，升序契约）。
集成断言：插入 3 条消息、limit=2 → `messages` seq `[2, 3]`（尾部、升序、首条 seq=2）；
空值口径：最近一页 `messages` 字段存在为 `[]`（`Some([])`）、补读页无该字段（`None` 省略）；
边界：`last_seq > max_seq` → `complete=true`、`events=[]`。

默认缺口上限 = `READBACK_MAX_GAP`（10_000，D4），由单测
`default_gap_limit_matches_core_constant` 锁定（`gap_limit()` 注入为常量级调参，
集成测试注入小值以避免提交 1 万条事件，见边界 5）。
