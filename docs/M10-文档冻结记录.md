## 2. 冻结后变更控制

1. 任何偏离冻结文档的实现，先按 AGENTS §3 提 **ADR 修订/新决策记录**，升版后再改；不得静默修改冻结文件。
2. 冻结文件哈希变化 → `pnpm verify:m10-00` 失败；必须同步更新 `docs/M10-文档冻结清单.json` 并在证据中记录原因/版本。
3. 代码/依赖/迁移/生成物由实现任务按 ADR/DoD 落地；落地时同批更新生成物、迁移、附录 C 与证据。
4. 未通过 Q3/Q5 spike 不写对应主路径；Q5 真实三运行时测试是 M10-02 前置门禁，不阻塞 M10-03。
