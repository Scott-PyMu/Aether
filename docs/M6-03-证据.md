## 2. ADR-023 v0.3 修订说明（§6-3 失效路径）

ADR-023 `实现要点 1` 的 `(col, ts)` 索引与 `§2.1-3` 未定义响应 COUNT 语义。M6-03 基准首轮实测（1e6 行、混合过滤分页）暴露两项问题：

1. `ORDER BY ts DESC, id DESC` 的 `id` 尾键不在 `(col, ts)` 索引内 → 低选择度过滤触发全量排序；实测 **P95 3.2s**（阈值 300ms）。
2. 多谓词 `COUNT(*)` 需逐行回表（如 `session_id=? AND actor=?` 经单列索引 + 表查找）；实测单次 **0.36–3.4s**。

按 ADR-023 §6-3「P95 不达标 → 修订索引/分页设计（本 ADR 修订），**不得改断言**」执行修订：

- 索引末位追加 `id` → `ts DESC, id DESC` 由索引逆向扫描全覆盖（页查询实测 0.1–6ms）；
- 查询不执行 `COUNT(*)`；响应为 `{ rows, limit, offset, has_more }`（多取一行探测）。

修订后基准（本轮证据 `dod2_bench.json`）：**1e6 行、40 次混合过滤分页查询，P50 <1ms、P95 5.2ms、max 5.7ms**（阈值 300ms 不变）。P95 断言零改动（AGENTS §6：不得改断言）。
