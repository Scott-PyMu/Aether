## 2. DoD 逐项结果

### DoD-1 格式/版本

- 首行 manifest 必须 `kind=manifest`、`v=1`；`v>1` → `import_invalid_format`（提示升级），`v<1` → 拒绝。
- `session_import` 只接受 `source=session-export`；`archive_import` 接受 `archive-export|auto-retention`（ADR-034 D-034-1）。
- payload `kind` ∈ `session|message|event|run|audit`；未知 kind → 整文件拒绝；未知 `event.type` → 跳过 + 警告（不执行、不广播）。
- manifest `rows`/`sha256` 与实际 payload 逐项校验；不一致 → `import_checksum_mismatch`。
- 上限：文件 ≤20 GiB、单行 ≤2 MiB、manifest ≤64 KiB；1 MiB 流式缓冲；超限 → `import_too_large`。
- 不执行导入内容：只做 JSON 解析/SQL 写入，不调用适配器、不访问网络、不执行事件 payload。

### DoD-2 原子性

- 真实导入：受理 → 异步流式校验 → `awaiting_restart` → 应用重启时在**无写者窗口**：
  `VACUUM INTO` 当前库快照 → staging 批量写入（≤1000 行/事务）→ `quick_check`/
  `foreign_key_check`/schema 校验 → `execute_restore` 原子切换（场景保护后缀
  `.pre-import-<ts>`）→ 重开验收。失败/中断回滚现场，既有库不变。
- `dry_run`：在快照上完成 staging/校验并返回预览，不切换、不写审计。
- 取消：每个批次/行边界检查；取消后删除 staging、保留既有库，返回 `import_cancelled`。
- kill -9：作业状态 `applying` 在下次启动被视为中断，标记 failed、清理 staging，**不自动续跑**。
- 大文件：`AETHER_M10_04_BIG_MIB` 流式样本；内存有界（1 MiB 缓冲 + 当前行）。

### DoD-3 ID/冲突/降级

- `remap`（默认）：session/message/run/event/audit 生成新 ULID；`parent_session_id`、
  `run.input_message_id`、`event.run_id` 等引用同步映射；`seq` 按会话重排（1..n，
  保持相对顺序，`UNIQUE(session_id,seq)` 不变量）。
- `preserve`：与目标库 ID 冲突 → `import_conflict`（`details.conflicts[]`），不覆盖、不合并。
- `client_msg_id` 同会话去重：重复消息跳过并计入 `summary.duplicates` + 警告。
- 标题缺失 → `Imported session <id 前 8 位>`；工作区缺失 → `NULL` + 警告；
  provider/model 缺失/停用 → 保留原值 + 警告（不自动选择/不产生费用）。
- 未知 runtime 引用插入 `disabled` 占位行（`imported_unknown_runtime`），避免 FK 断裂。

### DoD-6 安全

- **密钥字段 0 导入**：递归扫描导入行（含 payload）中的 `api_key`/`token`/`password`/
  `secret`/`private_key` 等字段 → `import_invalid_format`（D10）。
- 导入不触发工具执行/网络请求；事件 payload 原样落库但不执行。
- 路径：`source_path` canonicalize + 存在文件 + `.jsonl` 后缀；目录/相对路径/非 `.jsonl` → `path_rejected`。
- 无压缩容器（仅 JSONL），无解压炸弹面；单行/文件/嵌套深度上限。
- 审计/日志不记录文件内容/密钥；`import.*`/`export.*` detail 仅 job_id/计数/警告数/时长。
