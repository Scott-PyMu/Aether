## 2. 编辑性 P2（不影响文档侧闭合）

| 编号 | 级别 | 类型 | 问题 | 依据 | 建议 |
|---|---|---|---|---|---|
| P2-1 | P2 | 措辞 | `model_state` 的 provider 空语义写“任一启用 provider 中存在 → active”，未明确该 model 自身也需启用；若 model 行存在但已停用，可能被误判 active。 | ADR §2.1-4:114；设计 D7:517；ADR-010 B.4 | 改为“model 在任一启用 provider 中**存在且启用** → active；否则 invalid”；补停用 model 样本。 |
| P2-2 | P2 | 文档日期 | UI-UX §7.3 锚点表中 `session-provider-select` 行仍写“2026-10-23 v0.11”，当前为 v0.13；属历史日期未更新。 | UI-UX §7.3（M7-10 行） | 改为 v0.13 或删除日期，保持与头部一致。 |
| P2-3 | P2 | 历史表 | ADR §10 仍保留 v0.5 的“14 行真相表”、v0.7 的“2×P1”等历史行；作为历史记录可保留，但容易被误读为当前口径。 | ADR §10:399 等 | 在 §10 顶部注“历史行按当时版本，当前口径以 v0.8 为准”；或折叠历史表。 |
