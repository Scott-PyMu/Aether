**ADR-017 语义实现口径（核心层受控中断 + Mode R 重放）**：`pause` = 状态检查（`idle`/`running`/`waiting_permission`）→ 受控中断在途 run（`run.cancelled`，reason=`user_pause`）→ 记录 `PauseMarker{run_id, input_message_id}`（重放复用原输入消息，不新增消息行）→ `paused` → best-effort 下发 `session.pause`；`resume` = 有标记 → 复用原输入重放（`paused → running`）；无标记 → `paused → idle`；标记不跨重启（重启收口 `paused` 保留、不收口）。
